### Рекомендации для тестирования:

#### Вариант 1: Через Swagger UI (рекомендуется)
1. Откройте http://localhost:8001/docs
2. Найдите раздел "Marketplace"
3. Используйте кнопку "Authorize" для ввода токена существующего пользователя
4. Тестируйте endpoints через интерактивный интерфейс

#### Вариант 2: Создание пользователей вручную
1. Запустите скрипт создания пользователей:
   ```bash
   python backend/create_test_user.py
   ```
2. Используйте созданных пользователей для тестирования

#### Вариант 3: Использование существующих пользователей
1. Найдите существующих пользователей в БД
2. Используйте их email и пароль для входа
3. Получите токен через `/auth/email/login`
4. Используйте токен для тестирования API

### Сценарий полного тестирования:

1. **Создание пользователя-продавца**
   - Создать пользователя в БД
   - Войти и получить токен

2. **Создание бота/шаблона**
   - POST `/bots/` - создать бота
   - Получить ID созданного бота

3. **Размещение на маркетплейсе**
   - POST `/api/market/items` - создать товар на маркетплейсе
   - Указать `source_bot_id` и другие параметры
   - Установить `is_published: true`

4. **Создание пользователя-покупателя**
   - Создать второго пользователя в БД
   - Войти и получить токен

5. **Просмотр товаров покупателем**
   - GET `/api/market/items` - просмотреть список товаров
   - GET `/api/market/items/{id}` - просмотреть детали товара

6. **Использование товара покупателем**
   - POST `/api/market/reviews` - оставить отзыв на товар
   - Проверить обновление рейтинга товара
