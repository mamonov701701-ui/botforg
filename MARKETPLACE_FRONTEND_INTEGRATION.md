## Структура данных

### MarketItem (товар на маркетплейсе)
```typescript
{
  item_type: 'template' | 'scenario',
  source_bot_id?: number,        // Для шаблонов
  source_scenario_id?: number,   // Для сценариев
  title: string,
  description: string,
  additional_description?: string,
  price: number,
  category?: string,
  tags?: string[],
  is_published: true
}
```

### MarketOrder (заказ)
```typescript
{
  title: string,
  description: string,
  budget_min?: number,
  budget_max?: number,
  deadline?: string,
  category?: string,
  skills?: string[]
}
```

### FreelancerProfile (профиль исполнителя)
```typescript
{
  title: string,
  description?: string,
  hourly_rate?: number,
  skills?: string[]
}
```

## Как использовать

1. **Откройте страницу маркетплейса**: `/market`
2. **Выберите вкладку**: Templates, Scenarios, Customers или Freelancers
3. **Нажмите "Разместить"** (кнопка в правом верхнем углу)
4. **Заполните форму**:
   - Для шаблонов/сценариев: выберите "Из моих" или "Создать новый"
   - Заполните все обязательные поля
   - Укажите цену (0 = бесплатно)
   - Добавьте категорию и теги
5. **Нажмите "Опубликовать"**
6. **Товар появится на маркетплейсе**
