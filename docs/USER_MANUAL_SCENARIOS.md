# 🎓 Пошаговая инструкция: Работа со сценариями

> **Для кого:** Пользователи без навыков программирования  
> **Время чтения:** 10 минут  
> **Уровень:** Начинающий

---

## 📱 Что вы увидите в интерфейсе

### **Верхняя панель редактора:**

```
┌────────────────────────────────────────────────────────────────────┐
│ [🟢 Добавить блок] [➕ Новый сценарий] Сценарии: [🏠 Главный ▼] │ [💾 Сохранить ▼] │
└────────────────────────────────────────────────────────────────────┘
```

**Кнопки слева направо:**

1. **🟢 Добавить блок** (зеленая)
   - Открывает библиотеку доступных блоков
   - Используйте для добавления новых действий в сценарий

2. **➕ Новый сценарий** (с рамкой)
   - Создать новый сценарий в текущем боте
   - 3 варианта: пустой / из библиотеки / импорт файла
   - **Здесь выбираете шаблоны** из библиотеки

3. **Сценарии: [🏠 Главный ▼]** (dropdown с подписью и иконкой)
   - Подпись "Сценарии:" помогает понять назначение
   - Показывает текущий активный сценарий с иконкой
   - **Только сценарии этого бота** - быстрое переключение
   - **Это ваши "вкладки"** между разными частями бота
   - Иконки в стиле платформы (lucide-react)

4. **💾 Сохранить ▼** (желтая, с dropdown)
   - Основная кнопка: быстрое сохранение (Ctrl+S)
   - Dropdown: 4 опции сохранения
     - Быстрое сохранение (весь бот)
     - Сохранить бот как... (копия/переименовать)
     - Сохранить сценарий в библиотеку
     - Экспортировать в файл (.json)

## 🚀 Практический пример: Создаем бота магазина

### **Цель:** 
Создать бота с 3 сценариями:
1. Главное меню (приветствие)
2. Каталог товаров (показ товаров)
3. Оформление заказа (форма и оплата)

---

### **Шаг 1: Создаем главное меню**

#### 1.1. Открываем редактор
- Зайдите в "Личный кабинет" → "Мои боты"
- Нажмите на своего бота → кнопка "Редактор"

#### 1.2. Вы уже в сценарии "Главный"
По умолчанию первый сценарий создается автоматически.  
В dropdown вверху вы увидите: **"🏠 Главный"**

#### 1.3. Добавляем блоки приветствия
1. Нажмите **"🟢 Добавить блок"**
2. Выберите блок **"Начало"** (зеленый) - перетащите на холст
3. Снова нажмите **"🟢 Добавить блок"**
4. Выберите блок **"Сообщение"** - разместите рядом
5. В настройках блока введите: _"Добро пожаловать в наш магазин! 👋"_
6. Соедините блоки: от "Начало" к "Сообщение"

#### 1.4. Добавляем кнопки меню
1. **"🟢 Добавить блок"** → выберите **"Кнопки"**
2. В настройках добавьте кнопки:
   - "🛍️ Каталог"
   - "📦 Мои заказы"
   - "💬 Поддержка"
3. Соедините "Сообщение" с блоком "Кнопки"

#### 1.5. Сохраняем
Нажмите **"💾 Сохранить"** справа вверху

✅ **Готово!** Главный сценарий создан.

---

### **Шаг 2: Создаем сценарий "Каталог товаров"**

#### 2.1. Создаем новый сценарий
1. Нажмите кнопку **"➕ Новый сценарий"** в верхней панели
2. Выберите **"Пустой сценарий"** (или "Из библиотеки" если хотите шаблон)
3. Введите название: **"Каталог товаров"**
4. Выберите иконку: **📦 Каталог**
5. Нажмите **"Создать"**

#### 2.2. Вы переключились на новый сценарий
Холст пустой - это нормально! Вы в новом сценарии.  
Dropdown теперь показывает: **"📦 Каталог товаров"**

#### 2.3. Добавляем блоки каталога
1. **"🟢 Добавить блок"** → **"Сообщение"**
   - Текст: _"Выберите категорию товаров:"_
2. **"🟢 Добавить блок"** → **"Кнопки"**
   - Кнопки: "Одежда", "Обувь", "Аксессуары"
3. **"🟢 Добавить блок"** → **"Сообщение"**
   - Текст: _"Показываю товары категории..."_

#### 2.4. Сохраняем
**"💾 Сохранить"**

✅ **Готово!** Сценарий каталога создан.

---

### **Шаг 3: Связываем сценарии**

#### 3.1. Возвращаемся в "Главный"
1. Нажмите dropdown **"📦 Каталог товаров ▼"**
2. Выберите **"🏠 Главный"**
3. Вы вернулись в первый сценарий

#### 3.2. Добавляем переход к каталогу
1. **"🟢 Добавить блок"** → категория **"Системные"** → **"Переход к сценарию"**
2. Разместите этот блок после блока "Кнопки"
3. В настройках выберите: **Целевой сценарий: "Каталог товаров"**
4. Соедините кнопку "Каталог" с блоком "Переход к сценарию"

#### 3.3. Сохраняем
**"💾 Сохранить"**

✅ **Готово!** Теперь при нажатии кнопки "Каталог" пользователь перейдет в сценарий каталога.

## 🎯 Частые задачи

### **Задача 1: Скопировать сценарий из одного бота в другой**

**Способ 1 - Через файл:**
1. Откройте бот-источник → нужный сценарий
2. Нажмите **"Сохранить ▼"** → **"Экспортировать в файл"**
3. Файл скачается на компьютер
4. Откройте бот-получатель
5. Нажмите **"➕ Новый сценарий"** → **"Импорт из файла"**
6. Выберите скачанный файл → **"Создать"**

**Способ 2 - Через библиотеку (быстрее):**
1. Откройте бот-источник → нужный сценарий
2. Нажмите **"Сохранить ▼"** → **"Сохранить сценарий в библиотеку"**
3. Заполните форму (название, описание, категория)
4. Откройте бот-получатель
5. Нажмите **"➕ Новый сценарий"** → **"Из библиотеки"**
6. Выберите сценарий → **"Создать"**

---

### **Задача 2: Переименовать сценарий**

1. Откройте dropdown **"Сценарии ▼"**
2. Наведите на нужный сценарий
3. Справа появится кнопка **"⚙️"** (настройки)
4. Нажмите → выберите **"Переименовать"**
5. Введите новое название
6. Нажмите **"Сохранить"**

> 📌 **Примечание:** Главный сценарий нельзя переименовать - это точка входа в бот

---

### **Задача 3: Удалить ненужный сценарий**

**⚠️ Предупреждение:** Убедитесь, что на этот сценарий нет переходов из других!

1. Откройте dropdown **"Сценарии ▼"**
2. Справа от сценария нажмите кнопку **"🗑️"** (корзина)
3. Подтвердите удаление
4. Если есть ссылки - система покажет предупреждение

> 💡 **Совет:** Перед удалением экспортируйте сценарий - на всякий случай

---

### **Задача 4: Создать резервную копию всех сценариев**

**Быстрый способ:**
1. Откройте каждый сценарий (через dropdown "Сценарии")
2. Нажмите **"Сохранить ▼"** → **"Экспортировать в файл"**
3. Сохраните файлы в папку "Резервные копии/[Название бота]/[Дата]"

**Рекомендация:** Делайте резервные копии раз в неделю или после важных изменений

## ❗ Важные правила

### **Правило 1: Всегда сохраняйте перед переключением**
Хотя система автоматически предложит сохранить, лучше делать это вручную:
- Закончили редактировать → **"💾 Сохранить"**
- Переключаетесь на другой сценарий → **"💾 Сохранить"**

### **Правило 2: Один сценарий = одна задача**
✅ **Правильно:**
- Сценарий "Оплата" - только процесс оплаты
- Сценарий "FAQ" - только ответы на вопросы

❌ **Неправильно:**
- Сценарий "Всё" - и каталог, и оплата, и FAQ в одном

### **Правило 3: Используйте понятные названия**
✅ **Правильно:**
- "Оформление заказа доставки"
- "Техническая поддержка 24/7"
- "Акция - скидка 20%"

❌ **Неправильно:**
- "Сценарий 1"
- "Новый"
- "Test"

## 📊 Когда стоит создать отдельный сценарий?

### **✅ Создавайте новый сценарий когда:**

- Логически обособленная задача (оплата, FAQ, регистрация)
- Больше 10-15 блоков в одной ветке
- Нужно переиспользовать логику в нескольких местах
- Хотите чтобы разные люди работали над разными частями

### **❌ НЕ создавайте отдельный сценарий если:**

- Всего 2-3 блока
- Это просто вариация существующего сценария
- Нет переходов из других частей

## 🛠️ Решение проблем

### **Проблема: "Не могу найти где я создал определенный блок"**

**Решение:**
1. Откройте dropdown **"Сценарии ▼"**
2. Переключайтесь по сценариям и ищите нужный
3. Используйте поиск (Ctrl+F в браузере)

**Профилактика:**
- Давайте сценариям понятные названия
- Держите каждый сценарий компактным

---

### **Проблема: "Случайно удалил сценарий"**

**Решение:**
- Если не сохранили после удаления: обновите страницу (F5)
- Если сохранили: восстановите из резервной копии (экспорт)

**Профилактика:**
- Регулярно экспортируйте важные сценарии
- Сохраняйте в библиотеку

---

### **Проблема: "Слишком много сценариев, запутался"**

**Решение:**
1. Нарисуйте блок-схему на бумаге
2. Объедините похожие сценарии
3. Удалите неиспользуемые

**Профилактика:**
- Планируйте структуру до создания
- Рекомендуемое количество: 5-10 сценариев на бот

## 💡 Продвинутые советы

### **Совет 1: Создавайте "мастер-сценарии"**

Если у вас есть типовая последовательность, которую вы используете в каждом боте:
1. Создайте идеальный вариант
2. Экспортируйте → Сохраните в библиотеку
3. Дайте описательное название: "Шаблон: Регистрация пользователя v2"
4. При создании нового бота: Импорт → Из библиотеки

**Экономия времени:** Вместо 30 минут на создание - 30 секунд на импорт!

---

### **Совет 2: Версионность сценариев**

При внесении больших изменений:
1. Экспортируйте текущую версию
2. Назовите файл: `Сценарий-Оплата-v1-2024-11-07.json`
3. Вносите изменения
4. Если что-то пошло не так - импортируйте старую версию

---

### **Совет 3: Командная работа**

Если работаете в команде:
1. **Договоритесь о структуре:** кто какой сценарий делает
2. **Используйте библиотеку:** сохраняйте готовые части для коллег
3. **Версии:** указывайте версию и автора в описании
4. **Регулярные экспорты:** делитесь файлами через облако
