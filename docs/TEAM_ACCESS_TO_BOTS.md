# 🔐 Доступ участников команды к ботам владельца

## 📋 Текущая ситуация

### Как работает сейчас:

**Разработчик в команде проекта:**
- ✅ Имеет базовую роль `developer` (дает доступ к разделу "Боты")
- ✅ Может создавать **свои собственные боты**
- ✅ Может редактировать **только свои боты**
- ❌ **НЕ может** видеть/редактировать боты владельца проекта
- ❌ **НЕ имеет** доступа к ботам других участников команды

**Владелец проекта:**
- ✅ Видит и управляет **только своими ботами**
- ✅ Может приглашать участников в команду проекта
- ✅ Может назначать роли участникам команды

---

## 🎯 Как это работает технически

### Модель Bot:
```python
class Bot:
    owner_id  # ID владельца бота (кто создал)
    title
    username
    token
    ...
```

### Проверка доступа в API:
```python
# Все операции с ботами проверяют:
Bot.owner_id == current_user.id

# Это означает:
# - Только владелец может видеть свои боты
# - Только владелец может редактировать свои боты
# - Участники команды НЕ видят боты владельца
```

## ⚠️ Важные моменты

### 1. Боты принадлежат владельцу
- Каждый бот имеет `owner_id` - это владелец бота
- Владелец бота = тот, кто его создал
- Участники команды **не могут** редактировать боты владельца

### 2. Базовая роль определяет доступ к разделу
- Роль `developer` дает доступ к разделу "Боты"
- Но это означает доступ к **своим ботам**, а не к ботам владельца

### 3. Команда проекта ≠ доступ к ботам
- Участие в команде проекта дает базовую роль для доступа к платформе
- Но **не дает** автоматического доступа к ботам владельца
- Каждый пользователь работает со своими ботами

## 🔄 Возможные варианты развития

### Вариант 1: Текущая реализация (изолированные боты)
**Плюсы:**
- ✅ Четкое разделение: каждый работает со своими ботами
- ✅ Безопасность: нет доступа к чужим ботам
- ✅ Простота реализации

**Минусы:**
- ❌ Участники команды не могут помогать с ботами владельца
- ❌ Нужно передавать токены ботов для совместной работы

### Вариант 2: Совместный доступ к ботам владельца (нужно реализовать)
**Плюсы:**
- ✅ Участники команды могут редактировать боты владельца
- ✅ Удобно для совместной разработки
- ✅ Владелец контролирует доступ через команду

**Минусы:**
- ❌ Сложнее реализация (нужны проверки доступа)
- ❌ Нужно различать "свои боты" и "боты команды"

## 📝 Рекомендации

### Для владельца проекта:

1. **Если нужна совместная работа над ботами:**
   - Передавайте токены ботов участникам команды
   - Или создайте отдельные боты для каждого участника

2. **Если нужен контроль доступа:**
   - Используйте роли команды проекта для управления доступом
   - Регулярно проверяйте активных участников команды

3. **Для безопасности:**
   - Не давайте роль `owner` участникам команды
   - Используйте временные роли с сроком действия

### Для разработчика в команде:

1. **Вы можете:**
   - Создавать свои собственные боты
   - Использовать шаблоны для создания ботов
   - Просматривать аналитику (если есть доступ)

2. **Вы НЕ можете:**
   - Видеть боты владельца проекта
   - Редактировать боты владельца проекта
   - Управлять балансом владельца

3. **Для работы над ботами владельца:**
   - Запросите токен бота у владельца
   - Или создайте свой бот и поделитесь результатом

## 🔧 Техническая реализация (если нужно добавить доступ)

Если нужно дать участникам команды доступ к ботам владельца, нужно:

1. **Изменить запрос получения ботов:**
```python
# Вместо:
bots = db.query(Bot).filter(Bot.owner_id == current_user.id).all()

# Нужно:
# 1. Получить все команды, где пользователь участник
team_owners = db.query(TeamMember.owner_id).filter(
    TeamMember.user_id == current_user.id
).all()

# 2. Получить боты владельца И свои боты
bots = db.query(Bot).filter(
    (Bot.owner_id == current_user.id) |
    (Bot.owner_id.in_([to[0] for to in team_owners]))
).all()
```

2. **Изменить проверки доступа:**
```python
# Проверка: является ли пользователь владельцем ИЛИ участником команды владельца
def can_access_bot(bot_id: int, user_id: int, db: Session):
    bot = db.query(Bot).filter(Bot.id == bot_id).first()
    if not bot:
        return False
    
    # Владелец бота
    if bot.owner_id == user_id:
        return True
    
    # Участник команды владельца
    team_member = db.query(TeamMember).filter(
        TeamMember.owner_id == bot.owner_id,
        TeamMember.user_id == user_id
    ).first()
    
    return team_member is not None
```
