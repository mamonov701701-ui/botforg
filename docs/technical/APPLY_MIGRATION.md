# Применение миграции базовых ролей

## Быстрый старт

Выполните следующие команды в порядке:

### 1. Применить миграцию базы данных

```bash
cd backend
alembic upgrade head
```

Это создаст таблицу `base_roles` в базе данных.

### 2. Мигрировать существующие данные

Если у вас уже есть пользователи, выполните:

```bash
python migrate_base_roles.py
```

Это создаст записи `base_roles` для всех существующих пользователей на основе их текущей роли.

### 3. Перезапустить бэкенд

После миграции перезапустите бэкенд сервер, чтобы изменения вступили в силу.

## Проверка

После миграции проверьте в базе данных:
- Таблица `base_roles` создана
- Записи созданы для всех пользователей (если выполняли шаг 2)

## Откат (если необходимо)

```bash
alembic downgrade -1
```
