## 💡 Рекомендации по архитектуре

### 1. **Гибридный подход**
- **Структурированные поля** для часто используемых данных (status, name, email, phone)
- **JSON-поля** для динамических данных сценариев (`context`, `history`)

**Преимущества:**
- Быстрые запросы по структурированным полям
- Гибкость для сценариев через JSON
- Баланс между нормализацией и производительностью

### 2. **Постепенная миграция**
- Не ломать существующую функциональность
- Добавлять новые поля как nullable
- Мигрировать данные постепенно

### 3. **Обратная совместимость**
- Сохранить работу с `context` (JSON)
- Новые поля - дополнение, не замена
- API должен поддерживать оба подхода
