# Функции Чата

**Дата обновления:** 21 января 2026

## Обзор

Платформа BotForge теперь включает полнофункциональную систему обмена сообщениями, позволяющую пользователям общаться друг с другом, находить коллег и управлять контактами.

---

## Основные Функции

### 1. **Поиск Пользователей**

- **Где:** Раздел "Сообщения" → вкладка "Друзья"
- **Функционал:**
  - Поиск по публичному ID пользователя
  - Модальное окно с информацией о пользователе
  - Отображение статуса дружбы
  - Прямые действия: "Добавить в друзья" и "Написать сообщение"

**Как использовать:**
```
1. Перейдите в "Сообщения" → "Друзья"
2. Введите ID пользователя в поле поиска
3. Кликните на результат поиска
4. В модальном окне выберите нужное действие
```

---

### 2. **Управление Друзьями**

#### Добавление в друзья:
- Поиск пользователя → "Добавить в друзья"
- Запрос отправляется получателю
- Статус: "Запрос отправлен"

#### Принятие/Отклонение запросов:
- Вкладка "Запросы" отображает входящие запросы
- Кнопки: ✓ Принять | ✗ Отклонить

#### Удаление из друзей:
- Вкладка "Друзья" → меню (⋮) → "Удалить из друзей"
- Подтверждение через диалоговое окно

---

### 3. **Блокировка Пользователей**

**Где доступно:**
- Меню друга (⋮) → "Заблокировать"
- Модальное окно профиля → кнопка "Заблокировать"

**Эффект блокировки:**
- Пользователь не может отправлять вам сообщения
- Удаляется из списка друзей
- Добавляется в список заблокированных

**Разблокировка:**
- Вкладка "Заблокированные пользователи" → кнопка "Разблокировать"

---

### 4. **Чаты**

#### Типы чатов:
- **Приватные** - переписка один-на-один
- **Групповые** - чаты с несколькими участниками (в разработке)

#### Функции чата:
- Отправка текстовых сообщений
- Редактирование отправленных сообщений
- Удаление сообщений
- Ответ на сообщение (Reply)
- Реакции эмодзи
- Копирование текста сообщения

---

### 5. **Статус Прочтения** ✓✓

**Индикаторы:**
- **✓** (одна галочка) - Сообщение отправлено
- **✓✓** (две галочки, желтые) - Сообщение прочитано

**Логика работы:**
- **Приватные чаты:** прочитано = собеседник открыл чат
- **Групповые чаты:** прочитано = все участники открыли чат

**Автоматическое обновление:**
- При открытии чата обновляется `last_read_at`
- Галочки обновляются автоматически

---

### 6. **Управление Чатами**

#### Меню чата (⋮):
- **Закрепить** - чат появится вверху списка
- **Выключить уведомления** - отключить звуковые/визуальные оповещения
- **Удалить чат** - покинуть чат (для приватных) или удалить полностью (для групповых, только админ)

#### Счетчики:
- **Непрочитанные сообщения** - желтый бейдж на карточке чата
- **Общий счетчик** - над ссылкой "Личный кабинет" в хедере

---

### 7. **Email Уведомления**

**Когда отправляются:**
- При получении нового сообщения в чате
- Только если вы не в сети или не в чате

**Содержание:**
- Имя отправителя
- Превью сообщения (первые 100 символов)
- Ссылка для перехода в чат

**Настройка:**
- Отключение для конкретного чата: меню (⋮) → "Выключить уведомления"

## UI/UX Улучшения

### 1. **Автоматическое Закрытие Меню**

**Где применяется:**
- Меню чатов (⋮)
- Меню друзей (⋮)
- Меню сообщений

**Поведение:**
- Клик по кнопке (⋮) → меню открывается
- Клик вне меню → меню автоматически закрывается
- Клик по пункту меню → действие выполняется, меню закрывается

---

### 2. **Переключение Режимов Платформы**

**Режимы:**
- **Проекты** - личные боты, сценарии, аналитика
- **Платформа** - управление платформой, БФ команда, статистика

**Исправления:**
- Переключение работает с первого клика
- Список меню обновляется мгновенно
- Нет мерцания при переходе
- Из любого раздела можно переключиться на другой режим

**Логика:**
- Клик на кнопку → смена режима → переход на главную страницу режима
- URL меняется синхронно со списком навигации

## API Endpoints

### Дружба
```
POST   /chat/friends/request          - Отправить запрос в друзья
GET    /chat/friends                  - Список друзей
GET    /chat/friends/requests         - Входящие запросы
PUT    /chat/friendships/{id}/accept  - Принять запрос
PUT    /chat/friendships/{id}/decline - Отклонить запрос
DELETE /chat/friendships/{id}         - Удалить из друзей
```

### Блокировка
```
POST   /chat/blocked-users            - Заблокировать пользователя
GET    /chat/blocked-users            - Список заблокированных
DELETE /chat/blocked-users/{id}       - Разблокировать
```

### Чаты
```
GET    /chat/rooms                    - Список чатов
POST   /chat/rooms/private            - Создать приватный чат
GET    /chat/rooms/{id}               - Детали чата
DELETE /chat/rooms/{id}               - Удалить чат
PUT    /chat/rooms/{id}/pin           - Закрепить/открепить
PUT    /chat/rooms/{id}/mute          - Выключить/включить уведомления
```

### Сообщения
```
GET    /chat/rooms/{id}/messages      - Получить сообщения
POST   /chat/rooms/{id}/messages      - Отправить сообщение
PUT    /chat/messages/{id}            - Редактировать сообщение
DELETE /chat/messages/{id}            - Удалить сообщение
POST   /chat/messages/{id}/reaction   - Добавить реакцию
```

### Утилиты
```
GET    /chat/users/search?query=...   - Поиск пользователей
GET    /chat/unread-count             - Количество непрочитанных
PUT    /chat/status                   - Обновить онлайн-статус
```

## База Данных

### Новые Таблицы

**friendships** - связи между пользователями
- user_id, friend_id
- status: pending | accepted | declined | blocked

**user_statuses** - онлайн статус
- user_id, status, last_seen_at

**chat_rooms** - чаты
- public_id, room_type, name

**chat_participants** - участники чатов
- room_id, user_id, last_read_at, is_pinned, is_muted

**chat_messages** - сообщения
- room_id, sender_id, content, message_type
- reply_to_id, is_edited, is_deleted, is_read

**message_reactions** - реакции
- message_id, user_id, emoji

**blocked_users** - заблокированные
- blocker_id, blocked_id

---

## Безопасность

1. **Авторизация:** все эндпоинты требуют JWT токен
2. **Доступ к чатам:** проверка участия в `chat_participants`
3. **Блокировка:** заблокированные пользователи не могут отправлять сообщения
4. **Удаление:** soft delete для сообщений (is_deleted=true)

---

## Известные Ограничения

1. **Real-time обновления:** отсутствуют WebSocket, обновление каждые 30 секунд
2. **Групповые чаты:** базовая функциональность, без ролей
3. **Файлы:** пока только текстовые сообщения
4. **История:** нет экспорта переписки
