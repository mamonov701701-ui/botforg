# Роли пользователей BotForg

## Обзор

В платформе BotForg используется система ролей для управления доступом к разделам и действиям.

## Роли по умолчанию при регистрации

| Условие | Роль по умолчанию |
|---------|-------------------|
| Первый пользователь в системе | **owner** (Владелец) |
| Все последующие пользователи | **user** (Пользователь) |

**Важно:** Роль «Наблюдатель» (viewer) **не выдаётся** при регистрации. Она назначается вручную владельцем платформы для пользователей, которым нужен только просмотр без права изменений.

## Список ролей

| Роль | Описание |
|------|----------|
| **owner** | Владелец платформы. Полный доступ, включая BF Команду и управление ролями. |
| **admin** | Администратор. Всё кроме BF Команды. |
| **developer** | Разработчик. Боты, шаблоны, сценарии, аналитика. |
| **templates_manager** | Менеджер шаблонов. Шаблоны, публикация. |
| **support** | Поддержка. Только просмотр аналитики. |
| **viewer** | Наблюдатель. Только просмотр, без права создавать или изменять. |
| **user** | Пользователь. Может создавать ботов, шаблоны и сценарии. Роль по умолчанию для новых пользователей. |

## Права по умолчанию для роли «user»

Пользователь с ролью `user` может:
- Создавать, редактировать и удалять ботов
- Создавать, редактировать и удалять шаблоны
- Создавать и редактировать сценарии
- Просматривать аналитику
- Настраивать профиль и уведомления

## Изменение роли вручную

Для изменения роли пользователя используйте админ-скрипт:

```bash
python backend/scripts/set_user_role.py <email|user_id> <role>
```

Примеры:
```bash
python backend/scripts/set_user_role.py user@example.com owner
python backend/scripts/set_user_role.py 12 developer
```

Доступные роли: `owner`, `admin`, `developer`, `templates_manager`, `support`, `viewer`, `user`.

## Где назначается роль

- **Регистрация по email** — `backend/auth/email_routes.py` (register)
- **OAuth (Google, Yandex, Mail.ru)** — `backend/auth/routes.py` (oauth_callback)
- **Модель User** — `backend/models/user.py` (default="user")
- **Ручное изменение** — `backend/scripts/set_user_role.py`
