# Правила лицензирования Custom Blocks — Stage 7.9

Это продуктовые правила, не финальный текст оферты.

- Публичная карточка Маркета имеет один из режимов: **Бесплатно** или
  **Платно**. У платной карточки обязательны фиксированная цена и валюта.
- Бесплатный публичный блок можно сразу добавить в библиотеку. Операция
  создаёт право использования точной версии, отдельную запись добавления в
  библиотеку и автоматическое право распространения.
- Платный блок не выдаётся автоматически. Покупатель видит цену и связывается
  с автором во внутреннем чате. Расчёт — напрямую вне BotForg; платформа не
  принимает деньги, не делает checkout, escrow или refund. Автор вручную
  выдаёт право использования и, при необходимости, отдельно право распространения.
- Прямая выдача конкретному клиенту работает без публичной карточки Маркета.
  Она не превращается в access policy Маркета.
- Право использования ≠ право распространения ≠ добавление в библиотеку ≠
  владение блоком. Для публикации Scenario/Template с чужим платным блоком
  нужно отдельное право распространения; backend проверяет зависимости.
- Исходный автор определяется владельцем CustomBlock, не редактируемыми полями
  карточки. Опубликованный Scenario/Template сохраняет его имя и точную версию.
  Чужой блок нельзя переопубликовать от своего имени или получить его source.
- Опубликованный Free → Paid запрещён; Paid → Free разрешён. Черновик можно
  менять в обе стороны. Повышение цены опубликованной карточки также запрещено.
- Уже полученные права сохраняются при смягчении условий и архивировании.
  Архив закрывает новые выдачи, но не запрещает распространение обладателю
  уже приобретённого права. Отзыв персонального права блокирует этого
  получателя, security disable — отдельный глобальный механизм.
- Спор о платном блоке фиксирует покупателя, автора, точную версию, цену,
  валюту и снимок карточки. Решение и санкции доступны только уполномоченному
  администратору, с причиной и аудитом. Санкции распространяются на контент
  платформы, а не только на Custom Blocks.
- Старые карточки с `self_install`/`author_approval`/`explicit_grant` и
  `external_terms` сохраняются в backend для совместимости QA-данных;
  несовместимые предложения не показываются в обычном consumer-каталоге.
  Новые карточки создаются только по модели Free/Paid.
