# Система ролей и прав доступа BotForg

## Обзор

В платформе BotForg существует **две независимые системы ролей**:

1. **Базовые роли** (`role` в таблице `users`) - определяют доступ к разделам и функциям платформы
2. **BF-роли** (таблица `platform_roles`) - роли платформы для идентификации участников команды BotForg

---

## 📋 Базовые роли (Base Roles)

Базовые роли определяют **фактический доступ** пользователя к разделам и функциям платформы. Назначаются через раздел "BF Команда" → "Настройка" → "Базовая роль в проекте".

### 1. **owner** - Владелец проекта

**Описание:** Полный доступ ко всем разделам и действиям, включая финансы, аналитику, команду и настройки интеграций.

**Доступ к разделам:**
- ✅ Dashboard (личный кабинет)
- ✅ Боты
- ✅ Шаблоны
- ✅ Баланс
- ✅ Аналитика
- ✅ Команда проекта
- ✅ **BF Команда** (только для owner)
- ✅ Настройки

**Права на действия:**
- ✅ Создание, редактирование, удаление ботов
- ✅ Запуск/остановка ботов
- ✅ Создание, редактирование, удаление шаблонов
- ✅ Публикация шаблонов
- ✅ Просмотр баланса
- ✅ Пополнение баланса
- ✅ Экспорт транзакций
- ✅ Приглашение в команду проекта
- ✅ Редактирование ролей команды
- ✅ Удаление участников команды
- ✅ Настройки профиля
- ✅ Настройки интеграций
- ✅ Настройки уведомлений

**Особенности:**
- Единственная роль с доступом к разделу "BF Команда"
- Может назначать BF-роли другим пользователям
- Может изменять базовые роли участников команды

- Не имеет доступа к dashboard
- Используется для пользователей, которые не являются частью команды проекта

## 🏢 BF-роли (Platform Roles)

BF-роли - это **роли платформы BotForg**, которые назначаются владельцем (owner) через раздел "BF Команда". Они используются для **идентификации участников внутренней команды платформы**.

### Важно:
- **BF-роли НЕ определяют доступ к разделам и функциям**
- Доступ определяется **базовой ролью** (`role` в таблице `users`)
- BF-роли - это метки/титулы для участников команды платформы
- Пользователь может иметь несколько BF-ролей одновременно
- BF-роли могут иметь срок действия (временные роли)
- BF-роли могут быть отключены без удаления

### Доступные BF-роли:

#### 1. **BF Администратор**
- Высший уровень в команде платформы
- Обычно назначается администраторам платформы
- Не дает автоматических прав доступа (нужна соответствующая базовая роль)

#### 2. **BF Разработчик**
- Для разработчиков платформы
- Обычно назначается вместе с базовой ролью `developer`
- Идентифицирует разработчиков команды BotForg

#### 3. **BF Менеджер шаблонов**
- Для менеджеров шаблонов платформы
- Обычно назначается вместе с базовой ролью `templates_manager`
- Идентифицирует специалистов по шаблонам

#### 4. **BF Поддержка**
- Для сотрудников службы поддержки
- Обычно назначается вместе с базовой ролью `support`
- Идентифицирует команду поддержки

#### 5. **BF Аналитик**
- Для аналитиков платформы
- Идентифицирует специалистов по аналитике
- Может иметь любую базовую роль с доступом к аналитике

#### 6. **BF Модератор**
- Для модераторов контента
- Идентифицирует команду модерации
- Может иметь базовую роль с соответствующими правами

### Особенности BF-ролей:

1. **Назначение:**
   - Назначаются только владельцем (owner) через раздел "BF Команда"
   - Можно назначить несколько ролей одному пользователю
   - Можно назначить по 8-значному Public ID пользователя

2. **Срок действия:**
   - Могут быть бессрочными (по умолчанию)
   - Могут иметь срок действия (указывается в днях)
   - Автоматически истекают после указанной даты

3. **Активность:**
   - Могут быть активными или неактивными
   - Неактивные роли не учитываются, но сохраняются в базе
   - Можно временно отключить роль без удаления

4. **Удаление:**
   - Можно удалить отдельную BF-роль
   - Можно удалить все BF-роли пользователя (удаление из команды)

## 🔄 Взаимодействие базовых ролей и BF-ролей

### Примеры комбинаций:

1. **Владелец платформы:**
   - Базовая роль: `owner`
   - BF-роль: `BF Администратор`
   - Результат: Полный доступ + идентификация как администратор платформы

2. **Разработчик команды:**
   - Базовая роль: `developer`
   - BF-роль: `BF Разработчик`
   - Результат: Доступ к ботам и шаблонам + идентификация как разработчик команды

3. **Менеджер шаблонов:**
   - Базовая роль: `templates_manager`
   - BF-роль: `BF Менеджер шаблонов`
   - Результат: Доступ к шаблонам + идентификация как менеджер шаблонов

4. **Внешний разработчик (без BF-роли):**
   - Базовая роль: `developer`
   - BF-роль: нет
   - Результат: Доступ к ботам и шаблонам, но не является частью команды платформы

## 💡 Рекомендации по использованию

### Для владельца платформы (owner):

1. **Назначение базовых ролей:**
   - `admin` - для доверенных администраторов
   - `developer` - для разработчиков ботов
   - `templates_manager` - для специалистов по шаблонам
   - `support` - для службы поддержки
   - `viewer` - для наблюдателей

2. **Назначение BF-ролей:**
   - Используйте для идентификации участников команды платформы
   - Комбинируйте с соответствующими базовыми ролями
   - Используйте временные роли для проектов с ограниченным сроком

3. **Безопасность:**
   - Роль `owner` должна быть только у владельца платформы
   - Доступ к "BF Команде" только для `owner`
   - Регулярно проверяйте активные роли участников

### Для администраторов (admin):

- Имеют почти полный доступ, кроме управления BF-командой
- Могут управлять командой проекта
- Не могут изменять роли участников команды

### Для разработчиков (developer):

- Фокус на создании и управлении ботами
- Доступ к шаблонам для использования в ботах
- Нет доступа к финансовым операциям

---

## 📝 Примечания

1. **BF-роли не дают автоматических прав:**
   - Пользователь с BF-ролью "BF Администратор" но базовой ролью `user` не получит доступ к dashboard
   - Всегда проверяйте базовую роль для определения доступа

2. **Множественные BF-роли:**
   - Пользователь может иметь несколько BF-ролей одновременно
   - Это позволяет идентифицировать пользователя по разным аспектам его работы

3. **Временные роли:**
   - Используйте срок действия для временных проектов
   - Роль автоматически истечет после указанной даты

4. **Удаление из команды:**
   - Удаление всех BF-ролей пользователя удаляет его из команды платформы
   - Базовая роль при этом сохраняется
