# Тарифные планы BotForg

## Обзор

Тарифы определяют лимиты возможностей пользователей: количество ботов, право публикации сценариев, аналитику и размер команды.

## Тарифы

| Код | Название | max_bots | can_publish | can_use_analytics | max_team_members | can_publish_templates | can_sell_templates | can_view_marketplace_stats |
|-----|----------|----------|-------------|-------------------|------------------|------------------------|--------------------|----------------------------|
| free | Free | 1 | false | false | 0 | false | false | false |
| pro | Pro | 5 | true | true | 3 | false | false | false |
| team | Team | 20 | true | true | 10 | false | false | false |
| developer | Developer | 10 | true | true | 5 | true | true | true |

## Лимиты

### max_bots
Максимальное количество ботов, которые может создать пользователь. При попытке создать бота сверх лимита возвращается **403** с сообщением о необходимости перехода на Pro или Team.

### can_publish
Право публиковать сценарии (draft → published). На Free публикация недоступна. При попытке публикации возвращается **403**.

### can_use_analytics
Право использовать раздел аналитики. На Free аналитика недоступна. При обращении к аналитике возвращается **403**.

### max_team_members
Максимальное количество участников команды. На Free (0) команда недоступна. При добавлении участника сверх лимита возвращается **403**.

### can_publish_templates
Право публиковать шаблоны в маркетплейс. Доступно только на тарифе Developer.

### can_sell_templates
Право продавать шаблоны в маркетплейсе (пока mock). Доступно только на тарифе Developer.

### can_view_marketplace_stats
Право просматривать статистику своих шаблонов в маркетплейсе. Доступно только на тарифе Developer.

## Тариф Developer

**Для кого предназначен:** Разработчики ботов и шаблонов, которые хотят создавать и распространять готовые решения через маркетплейс BotForg.

**Возможности:**
- До 10 ботов
- Публикация сценариев
- Аналитика
- До 5 участников команды
- **Публикация шаблонов** — возможность добавлять шаблоны в маркетплейс
- **Продажа шаблонов** — монетизация шаблонов (пока mock)
- **Статистика маркетплейса** — просмотр метрик по своим шаблонам (просмотры, скачивания, продажи)

## API

### GET /plans
Список всех тарифов (без авторизации).

**Ответ:**
```json
{
  "total": 4,
  "items": [
    {
      "id": 1,
      "code": "free",
      "name": "Free",
      "limits": {
        "max_bots": 1,
        "can_publish": false,
        "can_use_analytics": false,
        "max_team_members": 0
      }
    }
  ]
}
```

### POST /me/plan
Смена тарифа текущего пользователя (mock, без оплаты). Для тестов и ручного назначения.

**Тело запроса:**
```json
{
  "plan_code": "pro"
}
```

**Ответ:**
```json
{
  "plan_code": "pro",
  "name": "Pro",
  "limits": {
    "max_bots": 5,
    "can_publish": true,
    "can_use_analytics": true,
    "max_team_members": 3
  }
}
```

## Текущий тариф пользователя

В ответе `GET /me` добавлено поле `plan_code` (по умолчанию `"free"`).

## Где проверяются лимиты

- **Создание бота** (`POST /bots/connect`, `POST /bots/`) — `check_max_bots`
- **Публикация сценария** (`POST /scenarios/{id}/publish`) — `check_can_publish`
- **Добавление в команду** (`POST /api/team/add-member`) — `check_max_team_members`
- **Аналитика** — `check_can_use_analytics` (интегрировать при необходимости)

## Сидер

Тарифы создаются автоматически при миграциях:
- `plans_012` — Free, Pro, Team
- `plans_developer_013` — Developer

Для повторного заполнения можно выполнить миграции заново или вставить записи вручную.
