# 📊 Руководство по маркетинговой аналитике

## Обзор

Система маркетинговой аналитики BotForg предоставляет комплексные инструменты для отслеживания эффективности ботов, анализа пользовательского поведения и оптимизации рекламных кампаний.

## 🎯 Ключевые возможности

### 1. Анализ в реальном времени
- **Онлайн пользователи** - текущее количество активных пользователей
- **Почасовая активность** - график активности за последние 24 часа
- **Пиковые часы** - автоматическое определение пиков активности

### 2. Метрики роста
- **Новые пользователи** - приток новых пользователей по дням
- **Активные пользователи** - дневная активность с трендами
- **Рост по периодам** - сравнение с предыдущим периодом (% изменения)

### 3. Удержание (Retention)
- **Retention 7 дней** - процент пользователей, вернувшихся в течение недели
- **Retention 30 дней** - процент пользователей, активных в течение месяца
- **Возвращающиеся пользователи** - пользователи, совершившие повторные визиты

### 4. Активность сообщений
- **Всего сообщений** - общее количество с ростом в %
- **Входящие/исходящие** - соотношение сообщений от пользователей и бота
- **Сообщений на пользователя** - средняя вовлеченность

### 5. Статистика ботов
- **Активные боты** - работающие боты
- **Неактивные боты** - остановленные или приостановленные
- **Распределение** - визуализация через круговую диаграмму

## 🛠️ Как использовать

### Выбор периода

**Предустановленные периоды:**
- **7 дней** - быстрый обзор недельной активности
- **30 дней** - месячный анализ
- **90 дней** - квартальный отчет

**Произвольный период:**
1. Нажмите кнопку "Свой"
2. Выберите дату "От" и "До"
3. Данные обновятся автоматически

### Фильтрация по ботам

Для анализа конкретного бота:
1. В фильтре "Бот" выберите нужного бота из списка
2. Все графики и метрики обновятся для выбранного бота
3. Выберите "Все боты" для общей статистики

### Настройка виджетов

**Управление видимостью:**
- В панели "Фильтры" нажмите на названия виджетов для переключения видимости
- Активные виджеты выделены желтым цветом

**Переключение типов графиков:**
- Каждый виджет поддерживает несколько типов визуализации:
  - 📊 **Столбцы** (Bar) - для сравнения дискретных значений
  - 📈 **Линия** (Line) - для отслеживания трендов
  - 🥧 **Круговая** (Pie) - для показа пропорций

### Экспорт данных

(Доступно для ролей BF_ANALYST и выше)

1. Нажмите кнопку "Экспорт" в правом верхнем углу
2. Данные сохраняются в формате JSON со всеми метриками за выбранный период

## 📈 Практические кейсы

### Кейс 1: Оценка эффективности рекламной кампании

**Задача:** Определить, привела ли рекламная кампания к росту пользователей

**Решение:**
1. Установите период "30 дней"
2. Проверьте график "Новые пользователи"
3. Обратите внимание на дни с резким ростом
4. Сравните "Рост по периодам" - если зеленая стрелка вверх и +X%, кампания успешна

### Кейс 2: Определение лучшего времени для рассылок

**Задача:** Найти оптимальное время для отправки сообщений

**Решение:**
1. Откройте виджет "Активность пользователей (24ч)"
2. Найдите пиковые часы (самые высокие столбцы)
3. В разделе "Пик активности" посмотрите автоматически определенный пик
4. **Рекомендация:** Запускайте рассылки за 1-2 часа ДО пика для максимального охвата

### Кейс 3: Оценка вовлеченности аудитории

**Задача:** Понять, насколько активно пользователи взаимодействуют с ботом

**Решение:**
1. Проверьте метрику "Сообщений на пользователя"
   - **< 3** - низкая вовлеченность, нужно улучшить контент
   - **3-10** - средняя вовлеченность
   - **> 10** - высокая вовлеченность, аудитория активна
2. Посмотрите на соотношение "Входящие/Исходящие"
   - Больше входящих = пользователи активно взаимодействуют
   - Больше исходящих = односторонняя коммуникация

### Кейс 4: Анализ удержания пользователей

**Задача:** Оценить, возвращаются ли пользователи в бот

**Решение:**
1. Проверьте "Retention 7д" и "Retention 30д"
   - **> 40%** (7д) - отличный результат
   - **20-40%** (7д) - хороший результат
   - **< 20%** (7д) - нужно улучшить engagement
2. Если retention падает:
   - Пересмотрите цепочки сообщений
   - Добавьте напоминания и триггеры
   - Проверьте, не раздражает ли бот частыми сообщениями

### Кейс 5: Сравнение эффективности разных ботов

**Задача:** Определить, какой бот работает лучше

**Решение:**
1. Выберите первого бота в фильтре "Бот"
2. Запишите ключевые метрики:
   - Новые пользователи
   - Retention 7д
   - Сообщений на пользователя
   - Пиковая активность
3. Повторите для второго бота
4. Сравните результаты и перенесите успешные практики

## 💡 Рекомендации для маркетологов

### Ежедневный мониторинг
- Проверяйте "Онлайн сейчас" для понимания текущей активности
- Следите за графиком "Активность пользователей (24ч)" для выявления аномалий

### Еженедельный анализ
- Оценивайте "Новые пользователи" за 7 дней
- Проверяйте "Retention 7д" - главный показатель здоровья продукта
- Анализируйте "Пиковую активность" для планирования контента

### Ежемесячный отчет
- Установите период "30 дней"
- Экспортируйте данные для отчета руководству
- Сравнивайте "Рост по периодам" для оценки динамики
- Проверяйте "Retention 30д" для долгосрочных трендов

### Оптимизация рекламы
1. **До запуска кампании:**
   - Запишите базовые метрики (новые пользователи/день, retention)
2. **Во время кампании:**
   - Ежедневно отслеживайте рост новых пользователей
   - Смотрите на spike (резкий рост) на графике
3. **После кампании:**
   - Сравните метрики до/после
   - Оцените retention новых пользователей (вернулись ли они?)
   - Рассчитайте ROI: (Прибыль - Затраты на рекламу) / Затраты * 100%

## 🔍 Интерпретация данных

### Зеленые индикаторы (хорошо)
- ↗️ Рост новых пользователей
- ↗️ Рост сообщений
- Высокий Retention (> 30%)
- Высокие пики активности

### Красные индикаторы (требует внимания)
- ↘️ Падение активных пользователей
- ↘️ Снижение retention
- Низкое соотношение сообщений на пользователя (< 2)
- Отсутствие новых пользователей

### Нейтральные индикаторы
- Стабильные метрики без изменений (может означать насыщение рынка)

## 🎨 Визуализация

### Типы графиков

**Столбчатые (Bar):**
- Лучше всего для сравнения значений по дням
- Используйте для "Новые пользователи" и "Сообщения по дням"

**Линейные (Line):**
- Идеально для отслеживания трендов
- Используйте для "Активные пользователи" и "Почасовая активность"

**Круговые (Pie):**
- Показывают пропорции и соотношения
- Используйте для "Retention", "Входящие/Исходящие", "Статистика ботов"

### Интерактивность
- Наведите курсор на точки графика для детальной информации
- Текущий час на графике выделен зеленым цветом
- Пиковые значения отмечены особым стилем

## 🚀 Продвинутые функции

### Сравнение периодов
Используйте метрику "vs пред. период" для понимания динамики:
- **+20%** = отличный рост
- **0-10%** = стабильное состояние
- **< 0%** = требуется вмешательство

### Сводная статистика
Внизу страницы находится раздел "Сводная статистика" с дополнительными метриками:
- Сообщений на пользователя
- Возвращающиеся пользователи (абсолютное число и %)
- Пиковый день недели
- Детализация входящих/исходящих сообщений

## ⚙️ Технические детали

### Обновление данных
- Данные обновляются автоматически при смене периода или фильтра
- Кнопка "Обновить" (↻) принудительно перезагружает данные
- Онлайн метрики обновляются при каждом открытии страницы

### Производительность
- Графики оптимизированы для больших объемов данных
- При периоде > 30 дней метки на оси X показываются с интервалами
- Lazy loading для тяжелых виджетов

### Доступ по ролям
- **Все роли:** Просмотр аналитики своих ботов
- **BF_ANALYST+:** Экспорт данных
- **BF_OWNER:** Аналитика всей платформы (раздел Platform Admin)

## 📱 Мобильная версия

На мобильных устройствах:
- Графики адаптируются под ширину экрана
- Виджеты располагаются в одну колонку
- Фильтры сворачиваются в компактный вид
- Все функции доступны в полном объеме

## 🆘 Решение проблем

**Проблема:** Графики показывают "Нет данных"
- **Решение:** Убедитесь, что выбранный бот имеет активность в указанном периоде

**Проблема:** Метрики равны нулю
- **Решение:** Это нормально для новых ботов без пользователей. Запустите бот и подождите первых взаимодействий.

**Проблема:** Онлайн пользователи = 0, но боты активны
- **Решение:** Пользователи считаются онлайн только при активном взаимодействии (не более 5 минут назад)
