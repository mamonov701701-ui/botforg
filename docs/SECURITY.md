# 🔐 Безопасность платформы BotForg

## Защита от вредоносного кода при импорте

### ❓ Может ли импорт навредить платформе?

**Короткий ответ: НЕТ** - если соблюдены все меры безопасности (что мы и сделали).

---

## 🛡️ Многоуровневая система защиты

### **Уровень 1: Валидация размера файла**
```
Максимальный размер: 5MB
Цель: Защита от DoS атак (отказ в обслуживании)
```

### **Уровень 2: Проверка формата**
```
Разрешены только: .json файлы
Блокируются: .exe, .html, .js, .php и другие исполняемые форматы
```

### **Уровень 3: Парсинг JSON**
```
Используется: JSON.parse() (безопасный встроенный парсер)
НЕ используется: eval(), Function(), new Function()
```

### **Уровень 4: Проверка структуры**
```
✓ Проверка глубины вложенности (макс. 10 уровней)
✓ Проверка количества блоков (макс. 500)
✓ Проверка количества связей (макс. 1000)
✓ Проверка длины строк (макс. 1000 символов)
```

### **Уровень 5: Блокировка опасных ключей**
```javascript
Блокируются:
- __proto__  (Prototype Pollution)
- constructor (изменение конструктора)
- prototype  (изменение прототипа)
```

### **Уровень 6: Санитизация HTML/JavaScript**
```
Используется: DOMPurify
Удаляются: <script>, <iframe>, onclick, onerror и т.д.
Остается: только чистый текст
```

### **Уровень 7: Валидация связей**
```
✓ Проверка что все edges ссылаются на существующие nodes
✓ Удаление "висячих" связей
```

## 🚫 Что БЛОКИРУЕТСЯ автоматически

### **1. XSS (Cross-Site Scripting)**

❌ **Вредоносный JSON:**
```json
{
  "nodes": [
    {
      "id": "1",
      "data": {
        "label": "<script>alert('Взлом!')</script>",
        "message": "<img src=x onerror='alert(1)'>"
      }
    }
  ]
}
```

✅ **После санитизации:**
```json
{
  "nodes": [
    {
      "id": "1",
      "data": {
        "label": "alert('Взлом!')",
        "message": ""
      }
    }
  ]
}
```
*Весь HTML/JavaScript удален, остался только текст.*

---

### **2. Prototype Pollution**

❌ **Вредоносный JSON:**
```json
{
  "__proto__": {
    "isAdmin": true,
    "permissions": ["all"]
  },
  "constructor": {
    "prototype": {
      "isAdmin": true
    }
  }
}
```

✅ **После валидации:**
```json
{}
```
*Опасные ключи полностью удалены.*

---

### **3. DoS (Denial of Service)**

❌ **Вредоносный файл:**
```json
{
  "nodes": [
    /* 1 000 000 блоков - файл 500MB */
  ]
}
```

✅ **Результат:**
```
❌ Ошибка импорта:

Файл слишком большой. Максимальный размер: 5MB

Файл не был загружен из соображений безопасности.
```

---

### **4. SQL Injection**

❌ **Вредоносный JSON:**
```json
{
  "name": "'; DROP TABLE scenarios; --",
  "description": "1' OR '1'='1"
}
```

✅ **После санитизации:**
```json
{
  "name": "'; DROP TABLE scenarios; --",
  "description": "1' OR '1'='1"
}
```
*Строки сохранены, но при сохранении в БД используются параметризованные запросы (prepared statements) - SQL injection невозможен.*

- [x] **Размер файла** ≤ 5MB

- [x] **Связи валидны** (source и target существуют)
- [x] **Опасные ключи удалены** (__proto__, constructor, prototype)
- [x] **HTML/JS санитизирован** (через DOMPurify)

## 🔒 Дополнительные меры безопасности

### **Frontend:**
1. **Content Security Policy (CSP)**
   ```
   script-src 'self'
   object-src 'none'
   base-uri 'self'
   ```

2. **No eval/Function**
   - Запрещено использование eval(), Function(), new Function()
   - Все данные обрабатываются как **DATA**, а не как **CODE**

3. **React автоматический экранирование**
   - React автоматически экранирует все переменные в JSX
   - `{variable}` безопасно, `dangerouslySetInnerHTML` НЕ используется

### **Backend (для будущей интеграции):**
1. **Параметризованные запросы**
   ```python
   # ✅ Безопасно
   cursor.execute("SELECT * FROM scenarios WHERE id = ?", (scenario_id,))
   
   # ❌ ОПАСНО (не используем)
   cursor.execute(f"SELECT * FROM scenarios WHERE id = {scenario_id}")
   ```

2. **Rate limiting**
   ```
   Максимум 10 импортов в минуту на пользователя
   ```

3. **Антивирус сканирование** (опционально)
   ```
   Интеграция с ClamAV для дополнительной проверки файлов
   ```

## 👤 Для пользователей

### ✅ Безопасно импортировать:
- Файлы экспортированные из BotForg
- Файлы из проверенных источников
- Файлы от коллег
- Публичные шаблоны из маркетплейса (после проверки)

### ⚠️ Будьте осторожны:
- Файлы из неизвестных источников
- Файлы от незнакомых людей
- Файлы с подозрительно большим размером

### ❌ НЕ импортировать:
- Файлы не в формате .json
- Файлы размером > 5MB
- Файлы с неизвестным содержимым

### 💡 Рекомендации:
1. Всегда проверяйте источник файла
2. Используйте только официальные шаблоны
3. При ошибке импорта - сообщите в поддержку
4. Экспортируйте резервные копии регулярно

## 👨‍💻 Для разработчиков

### Использование валидатора:

```typescript
import { validateScenarioFile } from '@/utils/scenarioValidator';

// Валидация файла
const validation = await validateScenarioFile(file);

if (!validation.isValid) {
  console.error('Ошибка:', validation.error);
  return;
}

// Безопасные данные
const { nodes, edges, metadata } = validation.sanitizedData!;
```

### Экспорт сценария:

```typescript
import { exportScenario } from '@/utils/scenarioValidator';

// Безопасный экспорт
const jsonString = exportScenario(nodes, edges, metadata);

// Скачивание файла
const blob = new Blob([jsonString], { type: 'application/json' });
const url = URL.createObjectURL(blob);
// ...
```
