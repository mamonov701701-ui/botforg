# 🎯 Варианты отображения проектов пользователя

## 📋 Текущая ситуация

Пользователь может быть участником нескольких проектов (команд) разных владельцев, но сейчас нет способа увидеть:
- В скольких проектах он участвует
- С какой ролью в каждом проекте
- Кто владелец каждого проекта
- Когда был добавлен в проект

---

## 🎨 Вариант 1: Виджет в сайдбаре (Компактный)

### Расположение:
В сайдбаре под профилем пользователя, перед меню навигации.

### Отображение:
```
┌─────────────────────────────────┐
│ 👤 Иван Иванов                  │
│ 🎭 Разработчик                  │
│ ID: 12345678                    │
├─────────────────────────────────┤
│ 📊 Мои проекты (3)              │
│                                 │
│ 🏢 Проект Виктора               │
│    👨‍💻 developer                 │
│                                 │
│ 🏢 Проект Марии                 │
│    👨‍💼 admin                    │
│                                 │
│ 🏢 Проект Петра                 │
│    👁️ viewer                    │
│                                 │
│ [Показать все →]               │
└─────────────────────────────────┘
```

### Плюсы:
- ✅ Всегда видно количество проектов
- ✅ Не занимает много места
- ✅ Быстрый доступ к информации

### Минусы:
- ❌ Ограниченное пространство (показывает только 2-3 проекта)
- ❌ Нужна кнопка "Показать все" для полного списка

## 📝 Что показывать в каждом проекте

1. **Владелец проекта:**
   - Имя
   - Email
   - Public ID

2. **Роль в проекте:**
   - Название роли (developer, admin, viewer и т.д.)
   - Иконка роли

3. **Статистика:**
   - Количество ботов в проекте
   - Дата добавления в проект

4. **Действия:**
   - Перейти к ботам проекта
   - Просмотреть команду проекта (если есть доступ)
