# ⚡ Быстрая справка: Сценарии

## 🎯 Главное за 30 секунд

**Сценарий** = отдельная часть бота для одной задачи

**Зачем разделять:**
- Легче редактировать
- Можно переиспользовать
- Не захламляется

**Как работать:**
1. Dropdown "Сценарии" → выбрать/создать
2. Добавить блоки → соединить
3. Нажать "Сохранить"
4. Связать через блок "Переход к сценарию"

---

## 🔘 Кнопки панели

| Кнопка | Действие | Когда нажимать |
|--------|----------|----------------|
| 🟢 **Добавить блок** | Открыть библиотеку блоков | Нужен новый блок в сценарий |
| ➕ **Новый сценарий** | Создать сценарий (3 варианта) | Добавить новую часть в бот |
| **Сценарии:** 🏠 [▼] | Переключение между сценариями | Работаете с другой частью |
| 💾 **Сохранить ▼** | Сохранить изменения (4 опции) | **После КАЖДОГО редактирования** |

> 💡 **Иконки:** Используются в стиле платформы (lucide-react) - единый визуальный стиль

> 🔐 **Безопасность:** Все импорты проверяются автоматически (7 уровней защиты)

---

## 📝 Быстрый старт

```
Шаг 1: Открыть редактор бота
Шаг 2: В сценарии "Главный" создать меню
Шаг 3: "➕ Новый сценарий" → выбрать вариант
Шаг 4: Создать логику второго сценария
Шаг 5: Dropdown "Сценарии" → вернуться в "Главный"
Шаг 6: Добавить блок "Переход к сценарию"
Шаг 7: Соединить кнопку с переходом
Шаг 8: "Сохранить" (Ctrl+S) → Готово!
```

---

## ⚠️ Важно запомнить

1. **Всегда сохраняйте** - кнопка 💾 "Сохранить"
2. **Главный сценарий нельзя удалить** - это точка входа
3. **Экспортируйте важное** - резервные копии
4. **Давайте понятные названия** - потом не запутаетесь

---

## 🆘 Частые ошибки

| Ошибка | Решение |
|--------|---------|
| "Не вижу созданный блок" | Вы в другом сценарии - переключитесь |
| "Не работает переход" | Проверьте блок "Переход к сценарию" |
| "Потерялись изменения" | Не нажали "Сохранить" |
| "Слишком много блоков" | Разбейте на несколько сценариев |
