# Future stage: User Profile & Account Settings

This is a separate roadmap stage, **not Stage 7.9 scope**. Stage 7.9 Admin
User Detail reads existing canonical user identity and associated records only.

Future work to specify and implement:

- Display Name policy and presentation of immutable User ID and email;
- phone, date of birth and 18+ eligibility, avatar;
- password change, active sessions/devices and two-factor authentication;
- notifications and minimal privacy controls;
- legal consents, account data export, deactivation and deletion;
- audit and consolidation of existing personal-account tabs: Profile,
  Integrations, Interface & Notifications, and BF Agent.

Google, Yandex and Mail.ru OAuth expansion is not part of this Stage 7.9 pass.
Security, privacy and legal requirements must be reviewed before this future
stage changes canonical user data or account lifecycle.
