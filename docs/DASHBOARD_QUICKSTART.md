# 🚀 Быстрый старт: Личный кабинет

## Доступ к личному кабинету

### 1. Перейти в ЛК
Откройте в браузере: `http://localhost:5173/dashboard`

### 2. Требования доступа
- Пользователь должен быть **авторизован**
- Роль пользователя должна быть **любой, кроме `user`**

Если не выполнено — покажется экран с предложением войти/зарегистрироваться.

## Тестирование ролей

### Изменить роль пользователя в БД
```sql
-- Установить роль owner (полный доступ)
UPDATE users SET role = 'owner' WHERE email = 'your@email.com';

-- Или другие роли:
-- 'admin', 'developer', 'templates_manager', 'support', 'viewer'
```

### Или через API (если есть эндпоинт)
```bash
curl -X PATCH http://localhost:8001/api/users/me/role \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{"role": "owner"}'
```

## Разделы ЛК

| Раздел | URL | Роли с доступом |
|--------|-----|-----------------|
| Главная | `/dashboard` | Все кроме `user` |
| Боты | `/dashboard/bots` | owner, admin, developer |
| Шаблоны | `/dashboard/templates` | owner, admin, developer, templates_manager |
| Баланс | `/dashboard/balance` | owner, admin |
| Аналитика | `/dashboard/analytics` | Все кроме `user` |
| Команда | `/dashboard/team` | owner, admin |
| Настройки | `/dashboard/settings` | owner, admin, developer |

## Проверка работы

### 1. Боковая навигация
- [ ] Отображаются только доступные разделы
- [ ] Активный раздел подсвечен
- [ ] Кнопка сворачивания работает

### 2. KPI на главной
- [ ] Отображаются 5 карточек
- [ ] Лента событий работает
- [ ] Быстрые действия доступны по ролям

### 3. RBAC
- [ ] Viewer не видит кнопки "Создать"
- [ ] Support не видит разделы "Баланс" и "Команда"
- [ ] Owner видит все разделы

### 4. Пустые состояния
- [ ] Показываются при отсутствии данных
- [ ] CTA-кнопки работают

## Устранение неполадок

### Проблема: "Доступ ограничен"
**Решение**: Проверьте, что пользователь авторизован и роль ≠ `user`

### Проблема: Не видно некоторых разделов
**Решение**: Это нормально — работает RBAC. Смените роль на `owner` для полного доступа.

### Проблема: Стили сломаны
**Решение**: 
1. Проверьте, что загружены CSS переменные в `theme.css`
2. Очистите кеш браузера (Ctrl+F5)

### Проблема: Ошибки в консоли
**Решение**: Проверьте, что backend запущен на порту 8001
