## 🛡️ Раздел "BF команда"

### Что это?
Раздел для управления пользователями платформы и назначения BF-ролей.

### Как назначить роль пользователю:

1. Зайдите в раздел **"BF команда"** (иконка щита в меню)
2. Нажмите кнопку **"Добавить по ID"** (справа от поиска)
3. В модальном окне введите:
   - **ID пользователя** (можно узнать в его личном кабинете)
   - **Выберите роль** из списка:
     - BF Администратор
     - BF Разработчик
     - BF Менеджер шаблонов
     - BF Поддержка
     - BF Аналитик
     - BF Модератор
   - **Срок действия** (дней, необязательно) - оставьте пустым для бессрочной роли
4. Нажмите **"Назначить роль"**

### Как найти ID пользователя:
- ID отображается в личном кабинете каждого пользователя
- Также ID показывается в таблице пользователей в разделе "BF команда"

### Возможности:
- ✅ Назначение временных и постоянных BF-ролей
- ✅ Поиск пользователей по email или имени
- ✅ Просмотр всех пользователей платформы
- ✅ Отключение пользователей (деактивация роли)

## 🛒 Маркетплейс и модерация шаблонов

### Кабинет разработчика (`/developer/templates`)

Доступен при тарифе **Developer**. Позволяет управлять шаблонами для маркетплейса.

**Статусы модерации:**
- **Черновик** — шаблон создан, не виден в маркетплейсе
- **На модерации** — отправлен на проверку администратору
- **Одобрен** — шаблон опубликован в маркетплейсе
- **Отклонён** — администратор отклонил с указанием причины

**Действия:**
- Кнопка «На модерацию» — отправить черновик на проверку (draft → pending)
- При отклонении отображается причина отказа — можно исправить и отправить заново

### Модерация (только owner)

Владелец платформы может одобрять или отклонять шаблоны через API:
- `POST /api/admin/market/templates/{id}/approve` — одобрить
- `POST /api/admin/market/templates/{id}/reject` — отклонить (тело: `{"reason": "причина"}`)

## 📝 Редактор сценария и проверка

1. Откройте **«Редактор»** в шапке сайта — откроется сценарий выбранного бота (`/editor/{id}`).
2. Кнопка **«Проверка сценария»** (или аналог в панели управления редактором) открывает окно с результатами:
   - незаполненные обязательные поля в блоках;
   - предупреждения и ошибки консистентности (переменные, связи между блоками, плейсхолдеры в тексте).
3. Тексты в этом окне отображаются **на русском языке**. Можно перейти к проблемному блоку на схеме из списка.
4. Если сервер временно не отдаёт список переменных конструктора, редактор всё равно можно использовать: проверка работает с доступными данными, пустой экран из‑за этого не возникает.

Подробные сценарии работы со сценариями см. также [USER_MANUAL_SCENARIOS.md](../USER_MANUAL_SCENARIOS.md) и [QUICK_REFERENCE.md](../QUICK_REFERENCE.md).

## ⚙️ Технические детали

### Backend API (только для owner):

- `GET /api/platform-admin/users` - список пользователей
- `GET /api/platform-admin/users/{id}` - детали пользователя
- `POST /api/platform-admin/roles` - назначить роль
- `PATCH /api/platform-admin/roles/{id}` - изменить роль
- `DELETE /api/platform-admin/roles/{id}` - удалить роль
- `GET /api/platform-admin/roles/available` - список ролей

### Backend API (для всех пользователей):

- `GET /api/my-roles` - получить свои BF-роли
- `POST /api/user/security/change-password` - смена пароля
- `POST /api/user/security/change-email` - смена email

### База данных:

- Таблица `platform_roles` - хранит назначенные BF-роли
- Поля: user_id, role_name, granted_by, granted_at, expires_at, is_active, notes

## 🐛 Если что-то не работает

### Проблема: Не могу войти
**Решение:**
- Убедитесь что backend запущен на порту 8001
- Убедитесь что frontend запущен на порту 5173
- Проверьте файл `backend/.env` - должны быть заполнены SECRET_KEY и JWT_SECRET
- Попробуйте очистить кеш браузера (Ctrl+Shift+R)

### Проблема: Ошибка при назначении роли
**Решение:**
- Проверьте что пользователь с указанным ID существует
- Проверьте что роль еще не назначена этому пользователю
- Откройте консоль браузера (F12) для деталей ошибки

### Проблема: Не вижу раздел "BF команда"
**Решение:**
- Этот раздел доступен только пользователям с ролью `owner`
- Проверьте свою роль в личном кабинете
