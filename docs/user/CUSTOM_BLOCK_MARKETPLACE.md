# Кастомные блоки в Маркете

В **Маркет → Кастомные блоки → Каталог** размещаются публичные карточки двух типов:
**Бесплатно** и **Платно**. Карточка относится к точной опубликованной версии блока.
Авторство и исходный код при получении доступа не передаются.

## Пользователю

- Бесплатный блок: нажмите **Добавить в мои блоки**. BotForg выдаст право
  использования, право распространения и добавит точную версию в библиотеку.
- Платный блок: карточка показывает фиксированную цену и валюту. Нажмите
  **Связаться с автором** — откроется существующий личный чат. Расчёт
  происходит напрямую между вами и автором, вне BotForg. BotForg не принимает
  платежи, не проводит возвраты и не является платёжным посредником.
- После подтверждения расчёта автор вручную выдаёт право использования. Только
  после этого нажмите **Добавить в мои блоки**. Выданное право само по себе не
  добавляет блок в библиотеку. Переписка в чате сама по себе права не создаёт.
- Если автор дал доступ напрямую, без карточки Маркета, версия появится в
  разделе предоставленных вам блоков; добавьте её в библиотеку отдельным действием.

Добавленная версия доступна в **ЛК → Библиотека блоков** и EditorV2 при
действующем праве. Для публикации собственного Scenario/Template с чужим платным
блоком дополнительно нужно отдельное **право распространения** от автора.
Бесплатный публичный блок получает это право автоматически; при публикации
указываются исходный автор и точная версия. Чужой блок нельзя переиздать как свой.

При споре о платном блоке можно сообщить о проблеме платформе. Данные карточки
и цены на момент обращения сохраняются отдельно от последующих изменений автора.

## Автору

В **Маркет → Кастомные блоки → Мои блоки** нажмите **Разместить блок** и выберите
свою опубликованную одобренную версию. Выберите **Бесплатно** либо **Платно**;
для платной карточки укажите фиксированную цену и валюту. Бесплатная карточка
открыта всем. Для платной карточки после личного расчёта выдайте пользователю
право использования; право распространения выдаётся отдельно по вашему решению.

Если карточка не нужна — на странице опубликованной версии используйте
**Предоставить доступ** конкретному пользователю. Это прямая выдача, а не
размещение в Маркете, и она не меняет владельца блока.

Опубликованную бесплатную карточку нельзя сделать платной задним числом.
Платную можно сделать бесплатной. Архив прекращает новые получения прав, но
не уничтожает уже приобретённые. Индивидуальный отзыв права и глобальная
блокировка по безопасности — отдельные действия. Исторические карточки со
старыми способами доступа доступны автору для управления, но несовместимые
карточки скрыты из обычного каталога; новые так не создаются.
