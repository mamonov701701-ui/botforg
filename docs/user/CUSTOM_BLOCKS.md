# Как создать свой блок

Откройте **Библиотека блоков → Создать свой блок**. Мастер проведёт через 9 шагов: название и назначение, условия применения, входные данные, соединения и выходные результаты, выполнение и настройки, ограничения, примеры, инструкцию и финальную проверку.

На шаге 3 вводите понятные названия входных данных. BotForg автоматически создаёт для них безопасные Machine Keys (машинные ключи), поэтому писать технические идентификаторы вручную не требуется. Connections (соединения) находятся на шаге 4, а JavaScript Execution (выполнение JavaScript) — на шаге 5.

Все 9 шагов видны как Responsive Tabs (адаптивные вкладки), визуально соединённые с карточкой текущего шага. На доступный шаг можно перейти одним нажатием; вкладка с блокирующей ошибкой отмечается небольшой красной точкой. Корректные шаги не получают лишних индикаторов, а предупреждения остаются внутри соответствующего шага и в итоговой проверке. Кнопки **Назад** и **Далее** также остаются доступны.

Draft (черновик) автоматически сохраняется в Backend (бэкенд) примерно через четыре секунды после изменения вместе с текущим шагом. На экране видны состояния «Сохранение…», «Сохранено» или «Ошибка сохранения». Кнопка **Сохранить черновик** остаётся для немедленного сохранения. После F5 или повторного открытия мастер восстанавливает последнюю серверную версию черновика; Backend Draft (серверный черновик) является Source of Truth (источником истины).

В Connections Contract (контракте соединений) можно выбрать 0 или 1 вход и от 0 до 32 выходов. Для каждого выхода BotForg создаёт стабильный Machine Key (машинный ключ). При нескольких выходах JavaScript возвращает выбранный ключ в `route`; при одном выходе маршрут однозначен, а блок без выходов является Terminal Block (терминальным блоком).

JavaScript-код выполняется не в браузере и не внутри Backend process (процесса бэкенда), а через отдельный изолированный Runner (раннер). Preview (предпросмотр) использует тот же Backend Execution Core (серверное ядро выполнения), что и Runtime (боевой рантайм). Сетевой доступ, файлы, секреты, пакеты и системные команды запрещены. Переносы строк и отступы исходного кода сохраняются без автоматического форматирования.

Опубликованная версия неизменяема. Для правки выберите **Создать новую версию**. Старая версия и её инструкция останутся у существующих сценариев. **Архивировать** скрывает версию из выбора для новых сценариев, но не ломает старые. **Восстановить** снова разрешает выбор; при нескольких опубликованных версиях для новых блоков используется самая новая.

Критическая ошибка проверки (пустое обязательное поле, неверный ключ параметра, отсутствие примера или инструкции, неподдерживаемое выполнение) запрещает публикацию. Исправьте ошибки в черновике и повторите проверку.

Названия шагов, пояснения, примеры и типичные ошибки в этой статье показываются приложением из того же источника, что мастер, поэтому актуальный интерактивный вариант всегда находится на странице **Как создать свой блок** в библиотеке.
