## 🚀 КАК ПРОТЕСТИРОВАТЬ

### **Шаг 1: Запустите серверы**

```powershell
# Terminal 1 - Backend
cd backend
.\venv\Scripts\Activate.ps1
uvicorn main:app --reload --port 8001

# Terminal 2 - Frontend
cd frontend
npm run dev
```

### **Шаг 2: Авторизуйтесь**

1. Откройте http://localhost:5173
2. Нажмите "Личный кабинет"
3. Войдите/Зарегистрируйтесь:
   - Email: `testuser@example.com`
   - Password: `password123`

### **Шаг 3: Создайте тестового бота**

```powershell
# В Terminal 1 (backend)
python create_test_bot.py
```

Скопируйте URL из вывода (например: `http://localhost:5173/editor/57`)

### **Шаг 4: Откройте редактор**

Откройте скопированный URL в браузере.

## 🐛 TROUBLESHOOTING

### **Сценарии не загружаются**
✅ Проверьте авторизацию (token в localStorage)
✅ Проверьте что backend запущен на порту 8001
✅ Откройте Network tab и проверьте запросы

### **401 Unauthorized**
✅ Перелогиньтесь
✅ Проверьте что token не expired

### **Сценарии не сохраняются**
✅ Проверьте консоль на ошибки
✅ Проверьте что scenarioStore.hasUnsavedChanges() === true
✅ Проверьте Network: должен быть PUT /scenarios/{id}
