# Блок «Сообщение»

Полный текст инструкции по блоку «Сообщение» и по остальным блокам редактора в едином формате хранится в исходнике приложения:

`frontend/src/pages/features/blockGuideRu.ts` — запись `message` в объекте `BLOCK_GUIDE_RU`.

Справка выводится на странице **«Возможности»** → **«Блоки редактора»** (`/features?tab=blocks`). При изменении формулировок правьте указанный файл, а не эту заглушку.

Техническое описание для агента: `docs/technical/editor_blocks_bf_agent.md` (раздел «Сообщение»).
