# Блок «Сообщение»

## 1. Что делает блок

Блок «Сообщение» отправляет пользователю текст в чат.

Дополнительно к сообщению можно:
- добавить вложения (картинку, гиф-анимацию или видео)
- добавить кнопки для перехода по сценарию или открытия ссылки

---

## 2. Когда использовать

Используйте блок «Сообщение», когда нужно:

- отправить пользователю текст  
- показать информацию (приветствие, подсказки, результат)  
- предложить выбор через кнопки  
- показать вложения (изображение, гиф-анимацию или видео)

---

## 3. Когда не использовать

Не используйте этот блок, если:

- нужно получить ввод от пользователя → используйте блок «Ввод»
- нужна логика условий → используйте «Условие»
- нужна задержка → используйте «Ожидание»
- нужен переход в другой сценарий → используйте «Перейти в сценарий»

---

## 4. Настройки блока

### 4.1 Текст сообщения (обязательно)

Это текст, который увидит пользователь.

Если поле пустое — блок не будет работать корректно.

---

### 4.2 Формат текста

Доступны режимы:

- простой текст — без разметки  
- формат с разметкой — оформление по простым правилам  
- формат разметки — ограниченная разметка, как на страницах в интернете  

#### В формате с разметкой поддерживается:

- **жирный текст**
- _курсив_
- ссылка: видимый текст и полный интернет-адрес задаются по правилам редактора

⚠️ Важно:
- вид текста зависит от предпросмотра  
- не все возможности формата с разметкой включены  

---

### 4.3 Вложения

Можно добавить к сообщению вложения (картинку, анимацию или видео).

#### Важно:

Один блок поддерживает только один тип вложения.

Нельзя смешивать:
- картинку и видео  
- гиф-анимацию и видео  
- и другие типы  

---

### 4.4 Тип вложения

Доступные варианты:

- без вложений  
- картинка  
- гиф-анимация  
- видео  

#### Ограничения:

- выбранный тип определяет допустимые файлы  
- если тип не совпадает — будет ошибка  
- при смене типа может потребоваться удалить файлы  

---

### 4.5 Файлы и ссылки

Можно добавить:

- файл с устройства  
- ссылку (полный интернет-адрес)

#### Ограничения:

- ссылка должна быть полной и в том виде, в каком её показывает браузер для защищённых страниц  
- файл должен соответствовать типу  
- максимальный размер — 50 МБ  

---

### 4.6 Кнопки

Можно добавить до 10 кнопок.

Кнопка содержит:
- надпись  
- действие  

---

### 4.7 Действия кнопок

#### Продолжить сценарий

Переход к следующему блоку.

Важно:
- работает только при наличии связи  
- без связи кнопка не работает  

---

#### Открыть ссылку

Открывает интернет-адрес.

Важно:
- ссылка обязательна  
- пустая ссылка → кнопка не работает  

---

## 5. Как работает предпросмотр

Предпросмотр показывает:

- текст  
- вложения  
- кнопки  

Особенности:

- это симуляция, а не реальный бот  
- поведение может отличаться  
- при нажатии на кнопку не создаётся сообщение пользователя  
- ссылка открывается в браузере  

---

## 6. Частые ошибки

Вложение не сохраняется → тип не совпадает  
Кнопка не работает → нет связи  
Ссылка не открывается → пустой адрес  
Нет оформления → выбран простой текст  

---

## 7. Примеры

Простое сообщение:
Добро пожаловать!

Сообщение с кнопками:
Выберите вариант

Сообщение с изображением:
Вот пример изображения

Кнопка со ссылкой:
Открыть сайт → укажите полный адрес страницы  

---

## 8. Чек-лист перед сохранением

- заполнен текст  
- выбран правильный тип вложения  
- файлы соответствуют типу  
- у кнопок есть связи  
- у ссылок заполнен адрес
