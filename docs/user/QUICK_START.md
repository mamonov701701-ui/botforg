## 🎯 ЗАПУСК (3 ПРОСТЫХ ШАГА)

### **Шаг 1: Запустите серверы**

```powershell
# Terminal 1 - Backend
cd C:\Users\mamon\botforg\backend
.\venv\Scripts\Activate.ps1
uvicorn main:app --reload --port 8001

# Terminal 2 - Frontend
cd C:\Users\mamon\botforg\frontend
npm run dev
```

### **Шаг 2: Войдите в систему**

1. Откройте http://localhost:5173
2. Нажмите **"Личный кабинет"** в шапке
3. Откроется модальное окно авторизации
4. Выберите вкладку **"Вход"** или **"Регистрация"**

### **Шаг 3: Создайте бота**

1. После входа перейдите в **"Мои боты"**
2. Нажмите **"+ Создать бота"**
3. Введите название бота → **"Далее"**
4. Выберите тип:
   - **"Подключить к каналу"** - для работы с клиентами (Telegram/WhatsApp/Max)
   - **"Создать для маркетплейса"** - шаблон для продажи другим пользователям
5. Если выбрали "Подключить к каналу":
   - Выберите канал (Telegram/WhatsApp/Max)
   - Введите токен/API ключ
   - Нажмите **"Подключить"**
6. После создания вы автоматически перейдёте в редактор

### **Шаг 4: Используйте редактор**

1. В редакторе выберите бота из dropdown "Мои боты"
2. Выберите сценарий из dropdown "Сценарии"
3. Нажмите **"Добавить блок"**
4. Выберите блок из библиотеки
5. Перетаскивайте блоки на холст
6. Сохраните изменения

## 🔧 СБРОС ПАРОЛЯ

Если забыли пароль, выполните:

```powershell
cd C:\Users\mamon\botforg
python reset_password.py
```

Или создайте скрипт `reset_my_password.py`:

```python
import sqlite3
import sys
sys.path.insert(0, 'backend')
from security import get_password_hash

email = "ваш@email.com"
new_password = "НовыйПароль123!"
hashed = get_password_hash(new_password)

conn = sqlite3.connect('backend/botforg.db')
cursor = conn.cursor()
cursor.execute("UPDATE users SET hashed_password = ?, password_hash = ? WHERE email = ?", (hashed, hashed, email))
conn.commit()
print(f"✅ Пароль для {email} сброшен на: {new_password}")
conn.close()
```

## 🐛 TROUBLESHOOTING

### **Ошибка 401 Unauthorized:**
Не авторизованы. Войдите через "Личный кабинет".

### **"Пользователь с таким email существует":**
Этот email уже зарегистрирован. Переключитесь на вкладку "Вход".

### **Забыли пароль:**
Используйте скрипт `reset_password.py` (см. выше).

### **Редактор исчезает после drag:**
Обновите страницу (F5). Баг исправлен в последней версии.

### **Сценарии не загружаются:**
1. Откройте консоль браузера (F12)
2. Проверьте Network tab
3. Если 401 - войдите в систему
4. Если 500 - перезапустите backend
