# Библиотека блоков

Раздел «Библиотека блоков» находится в обычном личном кабинете. В нём можно:

- посмотреть доступные блоки сценария;
- найти блок по названию или назначению;
- отфильтровать каталог по категории;
- открыть подробную русскую инструкцию и список основных параметров;
- перейти по кнопке «Открыть в редакторе» к существующему процессу выбора или создания рабочего пространства.

Системные коды блоков пользователю не требуются и в карточках не показываются. Старые служебные
блоки, которые сохранены только ради совместимости существующих сценариев, не предлагаются для
нового использования.

Администраторы платформы дополнительно видят раздел «Управление блоками» в платформенном режиме.
Он предназначен для проверки текущего каталога и контрактов и не изменяет системный JSON.
