# Маркетплейс BotForge

**Дата создания:** 21 января 2026  
**Статус:** В разработке (MVP)

## Обзор

Маркетплейс BotForge - это площадка для покупки и продажи шаблонов ботов, готовых сценариев, а также для размещения заказов на разработку и поиска исполнителей.

**Важно:** Платформа НЕ проводит денежные операции между пользователями. Все расчеты происходят напрямую между продавцом и покупателем вне платформы.

---

## Структура Маркетплейса

### 1. Шаблоны (Templates)

**Назначение:** Продажа и покупка готовых шаблонов ботов

**Типы шаблонов:**
- Бесплатные (price = 0)
- Платные
- Premium (featured)

**Карточка шаблона включает:**
- Изображение/превью
- Название
- Описание (краткое)
- Цена (₽ или "БЕСПЛАТНО")
- Рейтинг (звезды 1-5)
- Количество отзывов
- Количество продаж
- Информация о продавце:
  - Имя
  - Рейтинг продавца
  - Количество отзывов
- Категория
- Теги
- Метка "PREMIUM" для featured товаров

**Функционал:**
- Поиск по названию/описанию
- Фильтрация по категориям
- Сортировка (цена, рейтинг, популярность)
- Детальная страница товара (в разработке)
- Отзывы и оценки (в разработке)

---

### 2. Сценарии (Scenarios)

**Назначение:** Продажа и покупка готовых сценариев для ботов

**Отличия от шаблонов:**
- Сценарии - это логика и flow без UI
- Шаблоны - это полностью готовые боты с UI

**Структура:** Аналогична шаблонам

**Статус:** В разработке

---

### 3. Заказчики (Customers)

**Назначение:** Размещение заказов от заказчиков на разработку ботов и сценариев

**Карточка заказа включает:**
- Название заказа
- Описание требований
- Бюджет (диапазон или фиксированная сумма)
- Срок выполнения
- Категория
- Требуемые навыки (skills)
- Автор заказа:
  - Имя
  - Аватар
  - Рейтинг
- Дата создания
- Количество предложений от исполнителей

**Функционал:**
- Создание заказа
- Просмотр предложений от исполнителей
- Выбор исполнителя
- Чат с исполнителями (интеграция с существующей системой чата)
- Закрытие заказа
- Оставление отзыва

**Статус:** В разработке

---

### 4. Исполнители (Freelancers)

**Назначение:** Каталог исполнителей, предлагающих услуги по разработке ботов

**Карточка исполнителя включает:**
- Аватар
- Имя
- Специализация (title) - например "Разработчик ботов"
- Описание услуг
- Рейтинг (звезды 1-5)
- Количество отзывов
- Количество выполненных заказов
- Стоимость работы (₽/час или за проект)
- Навыки (skills/tags)
- Портфолио (примеры работ)

**Функционал:**
- Профиль исполнителя
- Отзывы клиентов
- Прямая связь через чат
- Предложение услуг для заказов

**Статус:** В разработке

- Категория (выпадающий список)
- Теги/навыки через запятую

**Для исполнителей:**
- Специализация (обязательно)
- Описание услуг (textarea, обязательно)
- Стоимость ₽/час (необязательно)

**Статус:** Форма готова, отправка данных будет реализована после создания backend API

## Кабинет разработчика (Creator Dashboard)

**Доступ:** Только тариф Developer.

Страница `/developer/templates` — «Мои шаблоны» — позволяет разработчикам управлять опубликованными шаблонами.

**Функционал:**
- Таблица: Название | Статус | Установки | Просмотры | Дата | Действия
- Пустое состояние: «У вас пока нет опубликованных шаблонов» + CTA «Создать и опубликовать шаблон»
- Кнопка «Мои шаблоны» на странице маркетплейса (видна только при тарифе Developer)

**API:**
```
GET    /api/market/my-templates    - Список шаблонов текущего пользователя (403 без Developer)
```

**Ответ:** массив объектов `{ id, name, status, moderation_status, moderation_rejection_reason, installs_count, views_count, created_at }`.

## Модерация шаблонов (Moderation Flow)

### Жизненный цикл шаблона

1. **draft** — черновик. Разработчик создаёт шаблон через маркетплейс. Шаблон не виден в публичном каталоге.
2. **pending** — на модерации. Разработчик нажимает «Отправить на модерацию» в кабинете `/developer/templates`. Шаблон ожидает проверки администратором.
3. **approved** — одобрен. Администратор (owner) одобряет шаблон. Шаблон появляется в публичном маркетплейсе.
4. **rejected** — отклонён. Администратор отклоняет с указанием причины. Разработчик видит причину отказа и может исправить и отправить заново (после правок — создать новый или изменить и снова отправить).

### API модерации

```
POST   /api/market/templates/{id}/submit              - Отправить на модерацию (draft→pending), Developer
POST   /api/admin/market/templates/{id}/approve       - Одобрить (pending→approved), owner
POST   /api/admin/market/templates/{id}/reject         - Отклонить (pending→rejected), owner, body: { reason }
```

### Публичный маркетплейс

В `GET /api/market/items` возвращаются **только шаблоны со статусом approved**. Шаблоны в статусе draft, pending, rejected скрыты от покупателей.

### Кабинет разработчика

- Отображается статус модерации (Черновик, На модерации, Одобрен, Отклонён)
- Кнопка «На модерацию» для шаблонов в статусе draft
- При отклонении отображается причина отказа (`moderation_rejection_reason`)

## API Endpoints (Планируемые)

### Шаблоны и сценарии
```
GET    /api/market/items?type=template&category=...     - Список товаров (только approved для шаблонов)
GET    /api/market/items/{id}                           - Детали товара
POST   /api/market/items                                - Создать товар
PUT    /api/market/items/{id}                           - Обновить товар
DELETE /api/market/items/{id}                           - Удалить товар
GET    /api/market/my-templates                         - Мои шаблоны (Creator Dashboard, Developer)
POST   /api/market/templates/{id}/submit                - Отправить на модерацию (Developer)
POST   /api/admin/market/templates/{id}/approve        - Одобрить (owner)
POST   /api/admin/market/templates/{id}/reject         - Отклонить (owner)
```

### Заказы
```
GET    /api/market/orders?status=open                   - Список заказов
GET    /api/market/orders/{id}                          - Детали заказа
POST   /api/market/orders                               - Создать заказ
PUT    /api/market/orders/{id}                          - Обновить заказ
POST   /api/market/orders/{id}/proposals                - Откликнуться на заказ
GET    /api/market/orders/{id}/proposals                - Список откликов
```

### Исполнители
```
GET    /api/market/freelancers?skills=...               - Список исполнителей
GET    /api/market/freelancers/{id}                     - Профиль исполнителя
POST   /api/market/freelancers                          - Создать профиль
PUT    /api/market/freelancers/{id}                     - Обновить профиль
```

### Отзывы
```
GET    /api/market/reviews?item_type=...&item_id=...    - Отзывы
POST   /api/market/reviews                              - Оставить отзыв
PUT    /api/market/reviews/{id}                         - Редактировать отзыв
DELETE /api/market/reviews/{id}                         - Удалить отзыв
```

## Безопасность

1. **Авторизация:** JWT токен для всех операций
2. **Права доступа:**
   - Редактировать товар может только владелец
   - Оставлять отзыв может только покупатель
   - Закрывать заказ может только автор заказа
3. **Модерация:** (в планах)
   - Проверка товаров перед публикацией
   - Жалобы на недобросовестных продавцов
4. **Оплата:** Платформа НЕ участвует в денежных операциях
