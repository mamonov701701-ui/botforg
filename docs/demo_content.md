# Демо-контент для новых пользователей

## Обзор

При регистрации нового пользователя автоматически создаётся демо-контент, чтобы личный кабинет не был пустым. Пользователь сразу видит готовые боты и шаблоны и может зайти в редактор.

## Что создаётся

| Тип | Количество | Описание |
|-----|------------|----------|
| Демо-бот | 1 | «Мой первый бот» с 2 сценариями |
| Шаблоны | 2 | «Лидогенерация», «Поддержка клиентов» |
| Сценарии в боте | 2 | «Главный», «Поддержка» |

### Демо-бот

- **Название:** Мой первый бот
- **Сценарии:**
  - **Главный** — точка входа, приветственное сообщение
  - **Поддержка** — сценарий связи с оператором

### Шаблоны

1. **Лидогенерация** — шаблон для сбора лидов и заявок (категория `lead_gen`)
2. **Поддержка клиентов** — шаблон для службы поддержки (категория `support`)

## Когда создаётся

Демо-контент создаётся один раз:

- при **регистрации по email** — сразу после создания пользователя;
- при **первом входе через OAuth** (Google, Yandex, Mail.ru) — для нового аккаунта.

Используется флаг `demo_content_created` в настройках пользователя (`UserSettings.interface_settings`), чтобы не создавать контент повторно.

## Флаг demo_content_created

- **Хранение:** `UserSettings.interface_settings["demo_content_created"]` (boolean)
- **API:** поле `demo_content_created` в ответе `GET /me/settings`
- **Использование:** фронтенд может показывать онбординг или подсказки

## Ручное создание

Для тестирования или повторного создания демо-контента:

```bash
python backend/scripts/seed_demo_content.py <email|user_id>
```

Примеры:
```bash
python backend/scripts/seed_demo_content.py user@example.com
python backend/scripts/seed_demo_content.py 12
```

> **Примечание:** скрипт создаёт контент только если `demo_content_created` ещё не установлен.

## Реализация

- **Сервис:** `backend/services/demo_content.py`
  - `create_demo_content_for_user(db, user_id)` — создание контента
  - `ensure_demo_content_created(db, user_id)` — создать при необходимости
- **Интеграция:**
  - `backend/auth/email_routes.py` — вызов при регистрации
  - `backend/auth/routes.py` — вызов при OAuth для нового пользователя

## Критерии готовности

- [x] После регистрации пользователь видит не пустой кабинет
- [x] Есть минимум 1 готовый бот и 2 шаблона
- [x] Пользователь может зайти в редактор и посмотреть сценарий
