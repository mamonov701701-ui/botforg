# Реализация разделения навигации личного кабинета

## ✅ Что реализовано

### 1. Переключатель режимов работы
- Добавлен переключатель в сайдбаре между двумя режимами:
  - **🔹 Проекты** - работа с собственными ботами и проектами
  - **🔹 Платформа** - управление платформой (только для owner и BF команды)

### 2. Разделение навигационных пунктов

#### Режим "Мои проекты":
- Главная
- Мои боты
- Сценарии
- Шаблоны
- Баланс
- Аналитика
- Команда
- Настройки

#### Режим "Управление платформой":
- Обзор платформы (`/dashboard/platform`)
- Пользователи и проекты (`/dashboard/platform/users`)
- Платформенная аналитика (`/dashboard/platform/analytics`)
- BF команда (`/dashboard/bf-team`)
- Настройки платформы (`/dashboard/platform/settings`)

### 3. Созданные страницы

1. **PlatformOverviewPage** - обзор платформы
   - Статистика (пользователи, проекты, боты)
   - Общая информация

2. **PlatformUsersPage** - пользователи и проекты
   - Список всех пользователей платформы
   - Поиск по email, имени, роли
   - Информация о BF-ролях пользователей
   - Готовность к расширению: просмотр проектов каждого пользователя

3. **PlatformAnalyticsPage** - платформенная аналитика
   - Заглушка для будущей аналитики
   - Планируется: метрики роста, использование, производительность

### 4. Автоматическое переключение режимов
- При переходе на `/dashboard/platform/*` или `/dashboard/bf-team` автоматически включается режим "Платформа"
- При переходе на обычные страницы - автоматически переключается на "Проекты"
- Режим сохраняется в localStorage

### 5. Права доступа
- Доступ к платформенному режиму: только для `role === 'owner'`
- В будущем можно расширить для участников BF команды с определенными правами

## 🎨 UX особенности

1. **Визуальное разделение**: Переключатель четко разделяет два режима работы
2. **Интуитивная навигация**: Каждый режим имеет свои пункты меню
3. **Автоматическое определение**: Система автоматически переключает режим при навигации
4. **Сохранение состояния**: Выбранный режим сохраняется между сессиями

## 🔮 Что можно доработать в будущем

1. **Расширение прав доступа**:
   - Добавить проверку BF-ролей для доступа к платформенному режиму
   - Разные уровни доступа для разных разделов

2. **Статистика платформы**:
   - API для получения статистики по всей платформе
   - Графики и метрики в PlatformOverviewPage

3. **Детальная страница пользователя**:
   - Просмотр всех проектов пользователя
   - Список ботов пользователя
   - История активности

4. **Расширенная аналитика**:
   - Графики роста пользователей
   - Метрики использования ботов
   - Анализ производительности системы

## 📝 Использование

1. **Для владельца платформы (owner)**:
   - Видит переключатель режимов в сайдбаре
   - Может переключаться между "Проекты" и "Платформа"
   - В режиме "Платформа" видит все административные разделы

2. **Для обычных пользователей**:
   - Видят только режим "Проекты"
   - Переключатель не отображается (если нет доступа)

## 🛠 Технические детали

- Режим хранится в `localStorage` с ключом `dashboard_mode`
- Проверка доступа: функция `hasPlatformAccess(user)` проверяет `user.role === 'owner'`
- Автоматическое переключение: useEffect отслеживает изменения `location.pathname`
