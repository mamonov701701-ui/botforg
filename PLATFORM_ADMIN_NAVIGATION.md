# Архитектура разделения навигации личного кабинета

## Концепция

Разделение личного кабинета на два режима работы:

### 1. **Мои проекты** (Проектный режим)
Работа с собственными ботами и проектами:
- Главная
- Мои боты
- Сценарии
- Шаблоны
- Баланс
- Аналитика проектов
- Команда проекта
- Настройки

### 2. **Управление платформой** (Административный режим)
Административная панель для анализа и управления всей платформой:
- Обзор платформы
- Пользователи и проекты
- Платформенная аналитика
- BF команда
- Настройки платформы

## Реализация

### Переключатель режимов
В сайдбаре добавлен переключатель с двумя опциями:
- 🔹 **Мои проекты** (по умолчанию)
- 🔹 **Управление платформой** (только для owner и BF команды)

### Навигация
- При переключении режима меняются доступные пункты меню
- Активный режим сохраняется в localStorage
- Визуально разделены две группы меню

### Права доступа
- **Owner** - полный доступ к обоим режимам
- **BF команда** (с соответствующими правами) - доступ к управлению платформой
