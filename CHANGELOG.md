## [2026-01-20] - Маркетинговая аналитика и управление платформой

### Добавлено
- **Комплексная маркетинговая аналитика**:
  - Почасовая активность пользователей за последние 24 часа с подсветкой текущего времени
  - График новых пользователей по дням
  - Активные пользователи по дням с линейными графиками
  - Метрики удержания (Retention 7д/30д)
  - Пиковая активность (часы и дни)
  - Анализ входящих/исходящих сообщений
  - Статистика ботов (активные/неактивные)
  - Онлайн пользователи в реальном времени

- **Настраиваемые фильтры аналитики**:
  - Выбор периода (7, 30, 90 дней)
  - Ручная установка произвольного периода (от-до)
  - Фильтрация по конкретному боту
  - Управление видимостью виджетов
  - Переключение типов графиков (столбцы, линии, круговые)

- **Platform Admin функционал**:
  - Страница "Обзор платформы" с ключевыми KPI (пользователи, проекты, боты, сценарии, сообщения)
  - Страница "Пользователи платформы" с поиском, фильтрацией и пагинацией
  - Детальная информация о пользователе с историей активности и списком ресурсов
  - Система блокировки/приостановки:
    - Временная блокировка пользователей с указанием срока
    - Постоянная блокировка с причиной
    - Предупреждения для пользователей
    - Блокировка отдельных ботов
    - Массовая блокировка всех ботов пользователя

- **Редактирование ботов и сценариев**:
  - Модальное окно редактирования названия и описания бота
  - Модальное окно редактирования названия, описания и категории сценария
  - Кнопка "Редактировать" в выпадающем меню каждой карточки

- **Новые API endpoints**:
  - `GET /api/platform-admin/stats` - общая статистика платформы
  - `GET /analytics/marketing` - комплексная маркетинговая аналитика
  - `POST /api/platform-admin/users/{user_id}/suspend` - приостановка пользователя
  - `POST /api/platform-admin/users/{user_id}/unsuspend` - разблокировка пользователя
  - `POST /api/platform-admin/bots/{bot_id}/suspend` - блокировка бота
  - `POST /api/platform-admin/bots/{bot_id}/unsuspend` - разблокировка бота
  - `GET /scenarios/my` - получение всех сценариев текущего пользователя

### Изменено
- Улучшена страница аналитики с реальными данными вместо фейковых
- Унифицирован дизайн страниц "Мои боты" и "Сценарии" для согласованности UI/UX
- Графики теперь отображают точки в виде идеальных кругов, а не овалов
- Почасовая активность показывает 24 часа с 3-часовыми интервалами на оси X
- Добавлены Y-оси с числовыми метками на всех графиках
- Улучшена читаемость и информативность всех виджетов аналитики

### Исправлено
- Исправлено перекрытие выпадающего меню действий нижними карточками (z-index, positioning)
- Исправлена проблема исчезновения списка пользователей при изменении размера страницы
- Исправлены нулевые значения на странице "Обзор платформы" - теперь показываются реальные данные
- Исправлено отображение списка сценариев (расхождение количества между разделами)
- Исправлено отображение статистики ботов (круговая диаграмма теперь показывает только 2 сегмента: активные/неактивные)

### Технические детали
**Backend**:
- Добавлены поля `is_suspended`, `suspension_type`, `suspension_reason`, `suspended_at`, `suspended_until`, `suspended_by_id` в модели `User` и `Bot`
- Добавлено поле `description` в модель `Bot`
- Создана миграция `d12ffa05e4c0_add_suspension_fields.py` для полей блокировки
- Создана миграция `e3a4b5c6d7e8_add_bot_description.py` для поля описания бота
- Расширен `backend/routers/platform_admin.py` для управления платформой
- Расширен `backend/routers/analytics.py` для маркетинговой аналитики
- Добавлены новые схемы в `backend/schemas/bot.py` и `backend/schemas/platformAdmin.py`

**Frontend**:
- Добавлены страницы:
  - `PlatformOverviewPage.tsx` - обзор платформы
  - `PlatformUsersPage.tsx` - список пользователей
  - `UserDetailPage.tsx` - детальная информация о пользователе
  - `PlatformAnalyticsPage.tsx` (резервная копия)
- Обновлён `AnalyticsPage.tsx` с полным набором маркетинговых виджетов
- Обновлены API клиенты: `analytics.ts`, `platformAdmin.ts`, `bot.ts`, `scenarios.ts`
- Улучшены компоненты `BotsPage.tsx` и `ScenariosPage.tsx`

## [2025-01-09] - Новый flow создания ботов

### Добавлено
- **Многошаговый процесс создания бота** с выбором типа:
  - Подключение к каналу (Telegram, WhatsApp, Max)
  - Создание для маркетплейса (шаблон без токена)
- **Поддержка нескольких каналов**:
  - Telegram (с проверкой токена через BotFather)
  - WhatsApp Business API
  - Max (новый мессенджер)
- **Новый API endpoint** `POST /bots/` для создания бота-шаблона без токена
- **Обновлённый UI** создания бота с пошаговым мастером

### Изменено
- Переработан компонент `NewBotModal.tsx`:
  - Шаг 1: Название бота
  - Шаг 2: Тип бота (подключить/маркетплейс)
  - Шаг 3: Выбор канала (если подключение)
  - Шаг 4: Ввод токена/API ключа (если подключение)
- Кнопка "Создать бота" в разделе "Мои боты" теперь открывает модальное окно вместо перехода на пустую страницу
- После создания бота пользователь автоматически перенаправляется в редактор

### Исправлено
- Исправлена проблема с переходом в редактор после создания бота для маркетплейса
- Улучшена обработка ошибок при создании бота

### Технические детали
- Добавлена схема `BotCreateSimple` в `backend/schemas/bot.py`
- Добавлен endpoint `create_bot` в `backend/routers/bot.py`
- Боты для маркетплейса создаются с placeholder токеном и username
- Автоматическое создание главного сценария при создании бота
