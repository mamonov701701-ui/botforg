# Changelog

Все значимые изменения в проекте BotForg будут документироваться в этом файле.

## [2026-01-21] - Маркетплейс: выбор из личного кабинета и улучшение UI

### Добавлено
- **Маркетплейс - выбор из личного кабинета**:
  - Возможность размещать существующие шаблоны/сценарии из личного кабинета
  - Переключатель "Из моих шаблонов/сценариев" ↔ "Создать новый"
  - Автоматическая загрузка списка ботов пользователя через API `getBots()`
  - Автоматическая загрузка списка сценариев пользователя через API `getMyScenarios()`
  - Выпадающий список для выбора существующего шаблона/сценария
  - Дополнительные поля для существующих элементов:
    - Цена для маркетплейса
    - Дополнительное описание для покупателей
  - Интеграция с существующими API endpoints

### Улучшено
- **UI/UX модальных окон маркетплейса**:
  - Все выпадающие списки (`<select>`) теперь имеют темный фон (`var(--surface)` - #11161d)
  - Все поля ввода (`<input>`, `<textarea>`) имеют темный фон для лучшей читаемости
  - Добавлен CSS класс `.marketplace-select` с темной цветовой схемой
  - Опции в выпадающих списках имеют темный фон (#11161d) с белым текстом
  - Использование `color-scheme: dark` для нативной поддержки темной темы браузера
  - Улучшена контрастность и читаемость всех элементов форм

### Исправлено
- Белый фон выпадающих списков заменен на темный (цвет бренда)
- Проблема с невидимостью опций в выпадающих списках на светлом фоне
- Всего обновлено 11 элементов формы (2 select, 7 input, 2 textarea)

### Технические детали
- Добавлен `useEffect` для безопасной загрузки шаблонов/сценариев с обработкой ошибок
- Реализовано состояние `sourceType` для переключения между режимами
- Добавлены стили `selectStyles` для глобального применения темной темы
- Все поля в модальных окнах используют `var(--surface)` вместо `var(--background)`

## [2026-01-21] - Система обмена сообщениями и улучшения UX

### Добавлено
- **Полнофункциональная система чата**:
  - Поиск пользователей по публичному ID
  - Модальное окно профиля пользователя с детальной информацией
  - Управление друзьями (добавление, принятие/отклонение запросов, удаление)
  - Блокировка/разблокировка пользователей
  - Приватные чаты с поддержкой текстовых сообщений
  - Статус прочтения сообщений (✓ отправлено, ✓✓ прочитано)
  - Редактирование и удаление сообщений
  - Ответы на сообщения (Reply)
  - Реакции эмодзи
  - Закрепление чатов
  - Отключение уведомлений для отдельных чатов
  - Email уведомления о новых сообщениях
  - Счетчик непрочитанных сообщений в хедере
  - Новые эндпоинты: `/chat/*` (30+ endpoints)

- **Новые модели БД**:
  - `friendships` - управление дружбой
  - `user_statuses` - онлайн статус
  - `chat_rooms` - чаты (приватные/групповые)
  - `chat_participants` - участники с настройками
  - `chat_messages` - сообщения с поддержкой Reply
  - `message_reactions` - реакции эмодзи
  - `blocked_users` - блокировка

### Улучшено
- **UX навигации**:
  - Автоматическое закрытие выпадающих меню при клике вне области
  - Мгновенное переключение между режимами "Проекты" и "Платформа"
  - Исправлено мерцание списка навигации
  - Список обновляется с первого клика без задержек
  - Переключение работает из любого раздела (включая "БФ команда")

- **Производительность чата**:
  - Автообновление чатов каждые 30 секунд (вместо 5)
  - Сообщения НЕ обновляются автоматически для предотвращения мерцания
  - Обновление только при отправке/получении нового сообщения

### Исправлено
- Удалена отладочная надпись "DEBUG: {json}" из раздела "Обзор платформы"
- Исправлен конфликт в useEffect при переключении режимов (dashboardMode из dependencies)
- Исправлено мерцание меню при быстрых кликах
- Исправлена проблема с непрочитанными сообщениями
- Backend поддержка двух схем хеширования паролей (bcrypt и pbkdf2_sha256)
- Vite proxy для `/chat` endpoints

### Документация
- Новый файл `docs/CHAT_FEATURES.md` с полным описанием функций чата
- Обновлена документация API endpoints
- Добавлены примеры использования

## [2026-01-20] - Платформенная аналитика и оптимизация

### Добавлено
- **Платформенная аналитика (Platform Analytics)**:
  - Новый endpoint `GET /api/platform-admin/analytics` для комплексной аналитики всей платформы
  - Полностью переработанная страница "Платформенная аналитика" с графиками и метриками
  - Выбор периода анализа (7, 30, 90 дней, произвольный)
  - KPI карточки: пользователи, боты (активные/всего), сценарии, пользователи ботов, сообщения, онлайн
  - Графики почасовой и дневной активности для всей платформы
  - Метрики роста (% изменения vs предыдущий период)
  - Пики активности (пиковый час, пиковый день)
  - Удержание: Retention 7д/30д, возвращаемость
  - Настраиваемые виджеты с переключением типов графиков
  - Аналитика по отдельным пользователям (поиск и сравнение)

### Оптимизировано
- **Производительность аналитики**:
  - Объединение множественных SQL запросов в единые агрегированные запросы
  - Использование `CASE WHEN` для условной агрегации вместо множественных запросов
  - Сокращение 20+ запросов к БД до 8-10 оптимизированных запросов
  - Добавлено логирование времени выполнения для мониторинга
  
### Исправлено
- Исправлена ошибка `NameError: name 'func' is not defined` в analytics.py
- Исправлена ошибка `NameError: name 'logger' is not defined` в analytics.py
- Исправлена ошибка SQLite `near "returning": syntax error` - переименован alias с зарезервированного слова
- Исправлено несоответствие моделей: разделены `bot_ids` (для Message) и `bot_instance_ids` (для BotUserState)
- Добавлены проверки на пустые списки ID перед выполнением запросов

## [2026-01-20] - Маркетинговая аналитика и управление платформой

### Добавлено
- **Комплексная маркетинговая аналитика**:
  - Почасовая активность пользователей за последние 24 часа с подсветкой текущего времени
  - График новых пользователей по дням
  - Активные пользователи по дням с линейными графиками
  - Метрики удержания (Retention 7д/30д)
  - Пиковая активность (часы и дни)
  - Анализ входящих/исходящих сообщений
  - Статистика ботов (активные/неактивные)
  - Онлайн пользователи в реальном времени

- **Настраиваемые фильтры аналитики**:
  - Выбор периода (7, 30, 90 дней)
  - Ручная установка произвольного периода (от-до)
  - Фильтрация по конкретному боту
  - Управление видимостью виджетов
  - Переключение типов графиков (столбцы, линии, круговые)

- **Platform Admin функционал**:
  - Страница "Обзор платформы" с ключевыми KPI (пользователи, проекты, боты, сценарии, сообщения)
  - Страница "Пользователи платформы" с поиском, фильтрацией и пагинацией
  - Детальная информация о пользователе с историей активности и списком ресурсов
  - Система блокировки/приостановки:
    - Временная блокировка пользователей с указанием срока
    - Постоянная блокировка с причиной
    - Предупреждения для пользователей
    - Блокировка отдельных ботов
    - Массовая блокировка всех ботов пользователя

- **Редактирование ботов и сценариев**:
  - Модальное окно редактирования названия и описания бота
  - Модальное окно редактирования названия, описания и категории сценария
  - Кнопка "Редактировать" в выпадающем меню каждой карточки

- **Новые API endpoints**:
  - `GET /api/platform-admin/stats` - общая статистика платформы
  - `GET /analytics/marketing` - комплексная маркетинговая аналитика
  - `POST /api/platform-admin/users/{user_id}/suspend` - приостановка пользователя
  - `POST /api/platform-admin/users/{user_id}/unsuspend` - разблокировка пользователя
  - `POST /api/platform-admin/bots/{bot_id}/suspend` - блокировка бота
  - `POST /api/platform-admin/bots/{bot_id}/unsuspend` - разблокировка бота
  - `GET /scenarios/my` - получение всех сценариев текущего пользователя

### Изменено
- Улучшена страница аналитики с реальными данными вместо фейковых
- Унифицирован дизайн страниц "Мои боты" и "Сценарии" для согласованности UI/UX
- Графики теперь отображают точки в виде идеальных кругов, а не овалов
- Почасовая активность показывает 24 часа с 3-часовыми интервалами на оси X
- Добавлены Y-оси с числовыми метками на всех графиках
- Улучшена читаемость и информативность всех виджетов аналитики

### Исправлено
- Исправлено перекрытие выпадающего меню действий нижними карточками (z-index, positioning)
- Исправлена проблема исчезновения списка пользователей при изменении размера страницы
- Исправлены нулевые значения на странице "Обзор платформы" - теперь показываются реальные данные
- Исправлено отображение списка сценариев (расхождение количества между разделами)
- Исправлено отображение статистики ботов (круговая диаграмма теперь показывает только 2 сегмента: активные/неактивные)

### Технические детали
**Backend**:
- Добавлены поля `is_suspended`, `suspension_type`, `suspension_reason`, `suspended_at`, `suspended_until`, `suspended_by_id` в модели `User` и `Bot`
- Добавлено поле `description` в модель `Bot`
- Создана миграция `d12ffa05e4c0_add_suspension_fields.py` для полей блокировки
- Создана миграция `e3a4b5c6d7e8_add_bot_description.py` для поля описания бота
- Расширен `backend/routers/platform_admin.py` для управления платформой
- Расширен `backend/routers/analytics.py` для маркетинговой аналитики
- Добавлены новые схемы в `backend/schemas/bot.py` и `backend/schemas/platformAdmin.py`

**Frontend**:

  - `PlatformOverviewPage.tsx` - обзор платформы
  - `PlatformUsersPage.tsx` - список пользователей
  - `UserDetailPage.tsx` - детальная информация о пользователе

## [2025-01-09] - Новый flow создания ботов

### Добавлено
- **Многошаговый процесс создания бота** с выбором типа:
  - Подключение к каналу (Telegram, WhatsApp, Max)
  - Создание для маркетплейса (шаблон без токена)
- **Поддержка нескольких каналов**:
  - Telegram (с проверкой токена через BotFather)
  - WhatsApp Business API
  - Max (новый мессенджер)
- **Новый API endpoint** `POST /bots/` для создания бота-шаблона без токена
- **Обновлённый UI** создания бота с пошаговым мастером

### Изменено
- Переработан компонент `NewBotModal.tsx`:
  - Шаг 1: Название бота
  - Шаг 2: Тип бота (подключить/маркетплейс)
  - Шаг 3: Выбор канала (если подключение)
  - Шаг 4: Ввод токена/API ключа (если подключение)
- Кнопка "Создать бота" в разделе "Мои боты" теперь открывает модальное окно вместо перехода на пустую страницу
- После создания бота пользователь автоматически перенаправляется в редактор

### Исправлено
- Исправлена проблема с переходом в редактор после создания бота для маркетплейса
- Улучшена обработка ошибок при создании бота

### Технические детали
- Добавлена схема `BotCreateSimple` в `backend/schemas/bot.py`
- Добавлен endpoint `create_bot` в `backend/routers/bot.py`
- Боты для маркетплейса создаются с placeholder токеном и username
- Автоматическое создание главного сценария при создании бота
