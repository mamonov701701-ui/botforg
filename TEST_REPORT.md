3. **Блок "Проверка выбора" (condition)**
   - ID: `node_condition`
   - Тип: `condition`
   - Позиция: (250, 350)
   - Переменная: `user_choice`
   - Оператор: `equals`
   - Значение: `Да`
   - Ветвление на два сценария

4. **Блок "Ответ: Да" (message)**
   - ID: `node_message_yes`

   - Позиция: (100, 500)

5. **Блок "Ответ: Нет" (message)**
   - ID: `node_message_no`
   - Тип: `message`
   - Позиция: (400, 500)

### ✅ 3. Соединения между блоками

Всего соединений: 4

1. `node_start` → `node_message_1`
2. `node_message_1` → `node_condition`
3. `node_condition` → `node_message_yes` (ветка TRUE, sourceHandle: "true")
4. `node_condition` → `node_message_no` (ветка FALSE, sourceHandle: "false")
